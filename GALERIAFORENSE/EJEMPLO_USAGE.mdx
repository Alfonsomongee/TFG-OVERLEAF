# 📊 Galería Forense del Apagón Ibérico 28-A

> **Sección Interactiva:** Consulta en tiempo real tablas y gráficos con datos procesados de fuentes oficiales
> (ENTSO-E, ICAI, Red Eléctrica, ESIOS).

## Introducción

El componente interactivo a continuación permite explorar los datos clave del incidente del **28 de abril de 2025**
que causó el apagón más grave de la historia eléctrica ibérica. Los datos incluyen:

- ⚡ **Parámetros de estabilidad**: Inercia, frecuencia, RoCoF
- ⚠️ **Violaciones de seguridad**: Criterios ICS comprometidos
- 🔗 **Reconfiguración de red**: Maniobras topológicas cronológicamente ordenadas
- 📊 **Demanda y recuperación**: Serie temporal 5 minutos con 1,083 puntos

### Cómo usar la galería

1. **Navega entre categorías** usando las pestañas en la parte superior
2. **Expande las tablas** haciendo clic en cada sección
3. **Consulta los gráficos interactivos** (pasa el ratón para ver detalles)
4. **Lee las anotaciones** bajo cada tabla para contexto técnico

## 🔍 Detalles de cada categoría

### ⚡ Estabilidad de Frecuencia

**Tabla: Distribución de Inercia a las 12:00 CEST (28-A)**

Antes del apagón, la inercia síncrona del sistema estaba **críticaente baja**:

- **NOROESTE**: 3.84 s (adequada, generación hidráulica + térmica)
- **NORTE**: 3.02 s (adequada)
- **ESTE**: 2.33 s (baja, dominada por nuclear)
- **CENTRO**: 1.84 s (BAJA ⚠️, zona crítica)
- **SUR**: 1.30 s (CRÍTICA 🔴, casi sin generación síncrona)
- **TOTAL**: 2.31 s (por debajo de mínimos de seguridad ~3.5-4.0 s)

**Implicación**: Con inercia tan baja, la frecuencia cae muy rápidamente ante pérdidas de generación.
El RoCoF (tasa de cambio) alcanzó ~1.85 Hz/s, lo que desencadenó:
1. **Esquemas UFLS** (Under Frequency Load Shedding) automáticos
2. **Disparos accidentales** de generadores por UV/OV (voltaje)
3. **Cascada de desconexiones** en 173 segundos

### ⚠️ Violaciones de Tensión (Criterios ICS)

**Tabla: ICS Criteria Violations by TSO (Tabla 7-1, ENTSO-E)**

Se violaron 7 criterios de seguridad:

| Criterio | Escala | Red Eléctrica | REN | RTE | Tipo de Incumplimiento |
|----------|--------|---------------|----|-----|--------|
| **OB** | 3 | ✓ | ✓ | — | Sobre-voltaje masivo |
| **L** | 2 | ✓ | ✓ | — | Pérdida de estabilidad |
| **T** | 2 | ✓ | — | — | Transitorios peligrosos |
| **T** | 0 | ✓ | ✓ | ✓ | Fallo transitorio generalizado |
| **G** | 2 | ✓ | ✓ | — | Desconexión de generadores |
| **RS** | 2 | ✓ | ✓ | — | Recuperación retrasada |
| **OV** | 1 | — | — | ✓ | Sobretensión en Francia |

**Criterios NO violados**: ON (operación normal), RRC (recuperación rápida), LT (límite de tiempo)

**Análisis**: La mayoría de violaciones ocurrieron en España y Portugal, indicando que el problema fue
**geográficamente concentrado** en la Península Ibérica. La violación de **T-2** (transitorios) sugiere
que los sistemas de protección no pudieron estabilizar el voltaje en los tiempos requeridos.

### 🔗 Estructura de Red

**Maniobras Topológicas (09:00-12:32 CEST, 28-A)**

Entre las 09:00 y las 12:32 (3.5 horas antes del apagón), Red Eléctrica realizó:
- **135+ cambios** en la configuración de la red
- **Apertura de líneas** de forma progresiva
- **Ajustes de setpoint** en el HVDC La Llogaia (10 veces)

Esto sugiere que el operador estaba intentando **mitigar congestiones** y **evitar sobrecargas**,
pero cada maniobra hacía la red **más frágil** y **menos resiliente** a perturbaciones.

Hito crítico: **12:16 CEST** - Última maniobra registrada (reconfiguración SS. Reyes).
Apenas 17 minutos después → **Disparo de Granada → Cascada → Blackout**

### 📊 Demanda y Recuperación

**Serie Temporal: Demanda Real Peninsular (27-A 21:00 → 29-A 03:00)**

**Fase 1: Período Normal (27-A 21:00 → 28-A 12:30)**
- Demanda típica de primavera
- Máximo: 27,453 MW (28-A 08:20 CEST)
- Patrón diurno-nocturno normal
- Generación solar en aumento (mañana)

**Fase 2: Inestabilidad (28-A 12:00-12:35)**
- Demanda: ~25,184 MW (12:30)
- Observaciones: Oscilaciones leves, renovables dominando
- Penetración no-síncrona: **82%** (renovables + importación)
- ⚠️ **Punto crítico**: Sistema al límite de estabilidad

**Fase 3: Blackout Total (28-A 12:35-13:00)**
- Demanda: **0 MW** durante ~25 minutos
- Causas: Desconexión en cascada de todas las cargas
- Velocidad: Desde 25 GW a 0 en <60 segundos
- Efecto cascada: Generadores se desconectan automáticamente (UV/OV)

**Fase 4: Recuperación Inicial (28-A 13:05-15:00)**
- 13:05: 37 MW (plantas de black start: Aguayo, Castejón, Cortes)
- 13:10: 204 MW
- 13:20: 431 MW
- 14:00: 1,346 MW (5.3% recuperado)
- 15:00: 2,559 MW (10.1%)
- Velocidad: ~100-150 MW/min (controlada)

**Fase 5: Recuperación Lenta (28-A 15:00 → 29-A 09:00)**
- 16:00: 3,445 MW (13.6%)
- 17:00: 5,380 MW (21.2%)
- 18:00: 6,069 MW (23.9%)
- 20:00: 9,565 MW (37.8%)
- 22:00: 13,236 MW (52.3%)
- 29-A 00:00: 15,300 MW (60.5%)
- 29-A 09:00: ~25,000+ MW (95%+ nominal)

**Duración total**: 20 horas 57 minutos (desde 12:33 hasta 09:30 aprox.)

**Análisis**: La recuperación fue extraordinariamente **lenta** debido a:
1. Generadores térmicos necesitan tiempo para sincronizar
2. Plantas de gas necesaban re-ignicionar (cooling down)
3. Restricciones de rampa de carga por estabilidad
4. Necesidad de verificación manual de parámetros

## 💡 Conclusiones de la Galería

### Hallazgos Principales

1. **Inercia críticamente baja** → 2.31 s (debería ser >4.0 s)
   - Culpable: 82% penetración renovable no-síncrona
   - Solución: Más generadores síncronos o SynCon/BESS-GFM

2. **Violaciones ICS generalizadas** → 7 de 11 criterios violados
   - Indica: Fallo múltiple del sistema, no uno singular
   - Sistema en estado de "operación frágil"

3. **Maniobras pre-apagón** → 135 cambios en 3.5 horas
   - Indica: Operador consciente del peligro, intentando mitigar
   - Pero: Cada cambio aumentaba fragilidad, paradójicamente

4. **Recuperación lenta** → 21 horas totales
   - Comparar con: Argentina 2019 (11h), Texas 2021 (5h)
   - Implicación: Falta de coordinación REE-REN-RTE

## 🔧 Personalización Avanzada

Si quieres **agregar más datos** a la galería, puedes:

### Opción 1: Agregar más tablas (sin programar)

Edita `src/components/GalleryForensic/GalleryForensic.jsx`, línea ~70:

```javascript
{
  id: 'rocof-analysis',
  name: 'RoCoF Máximo por Período',
  source: 'Cálculos basados en Informe ENTSO-E',
  type: 'table',
  data: [
    { period: '12:32:57→12:33:29', rocof_hz_per_s: -1.85, status: '🔴 Crítico' },
    { period: '12:33:29→12:35:00', rocof_hz_per_s: -0.92, status: '⚠️ Severo' },
    { period: '13:05:00→13:10:00', rocof_hz_per_s: 0.15, status: '✓ Normal' },
  ],
  columns: ['period', 'rocof_hz_per_s', 'status'],
}
```

### Opción 2: Agregar gráficos (necesita JSON)

Si tienes datos de frecuencia en PSCAD o mediciones REE:

```json
{
  "data": [
    { "datetime": "2025-04-28T12:30:00Z", "frequency_hz": 50.0 },
    { "datetime": "2025-04-28T12:31:00Z", "frequency_hz": 49.8 },
    { "datetime": "2025-04-28T12:32:00Z", "frequency_hz": 48.5 },
    ...
  ]
}
```
