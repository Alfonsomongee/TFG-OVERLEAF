✅ PASO 1: Verificar estructura de Docusaurus
────────────────────────────────────────────────────────────────────────────
Tu proyecto debe tener:
  docusaurus/
  ├── src/
  │   ├── components/          ← Aquí van los nuevos componentes
  │   └── pages/
  ├── static/
  │   └── data/
  │       └── processed/        ← Aquí irán los JSONs de datos
  ├── docs/
  ├── docusaurus.config.js
  └── package.json

Si no tienes `/src/components/`, créalo:
  $ mkdir -p src/components/GaleriaForense


✅ PASO 2: Instalar Recharts
────────────────────────────────────────────────────────────────────────────
En la raíz de tu proyecto Docusaurus:

  $ npm install recharts

Verifica que aparece en package.json:
  "recharts": "^2.10.0" (o versión similar)


✅ PASO 3: Copiar archivos de componentes
────────────────────────────────────────────────────────────────────────────
Copia TODOS estos archivos a src/components/GaleriaForense/:

  ├── TimelineManoeuvres.jsx
  ├── TimelineManoeuvres.module.css
  ├── ICSViolationsGrid.jsx
  ├── ICSViolationsGrid.module.css
  ├── InertiaStackedBar.jsx
  ├── InertiaStackedBar.module.css
  ├── PowerCapacityComparison.jsx
  ├── PowerCapacityComparison.module.css
  ├── LinesAvailability.jsx
  ├── LinesAvailability.module.css
  ├── index.js
  ├── hooks/
  │   └── useRealData.js
  └── README.md


✅ PASO 4: Crear estructura de datos (opcional si tienes JSONs reales)
────────────────────────────────────────────────────────────────────────────
Si tienes datos reales, crea:
  static/data/processed/
  ├── 28A_demand.json
  ├── 28A_generation_mix.json
  ├── 28A_price.json
  ├── 28A_balance.json
  └── 28A_capacity.json

SI NO tienes JSONs, los componentes funcionan igual con datos hardcodeados ✅


✅ PASO 5: Crear página en Docusaurus
────────────────────────────────────────────────────────────────────────────
Opción A: Página JSX
  Crea: docs/analisis-forense.jsx
  (Ver EJEMPLO_INTEGRACION.jsx para template completo)

Opción B: Página MDX
  Crea: docs/analisis-forense.mdx
  E incrusta componentes así:
  
    import { TimelineManoeuvres } from '@site/src/components/GaleriaForense';
    import BrowserOnly from '@docusaurus/core/lib/client/components/BrowserOnly';
    
    # Análisis Forense
    
    <BrowserOnly>
      {() => <TimelineManoeuvres />}
    </BrowserOnly>


✅ PASO 6: Probar localmente
────────────────────────────────────────────────────────────────────────────
En la raíz del proyecto:
  $ npm run start

Abre en navegador:
  http://localhost:3000/docs/analisis-forense (o tu ruta)

Verifica:
  ☐ Se carga sin errores en Console
  ☐ Gráficos se renderizan (no quedan en blanco)
  ☐ Colores son correctos (fondo oscuro, acentos azul/ámbar/rojo)
  ☐ Tooltips funcionan (hover desktop, click mobile)
  ☐ Es responsive (prueba en 380px, 768px, 1200px)
  ☐ No hay warnings sobre React/Recharts


✅ PASO 7: Build para producción
────────────────────────────────────────────────────────────────────────────
  $ npm run build

Verifica que no hay errores. Si los hay, mira Console/stderr.


✅ PASO 8: Deploy
────────────────────────────────────────────────────────────────────────────
Despliega como normalmente hagas tu Docusaurus (Vercel, Netlify, etc.)

PROBLEMA: "Cannot find module 'recharts'"
SOLUCIÓN: npm install recharts


PROBLEMA: "TimelineManoeuvres is not exported from index.js"
SOLUCIÓN: Verifica que index.js tiene todas las exportaciones y está en la ruta correcta


PROBLEMA: "Gráficos quedan en blanco"
SOLUCIÓN:
  1. Abre DevTools → Console, busca errores
  2. Verifica Recharts está instalado: npm list recharts
  3. Recarga la página (Ctrl+Shift+R hard refresh)


PROBLEMA: "CSS no se aplica"
SOLUCIÓN:
  1. Verifica que archivos .module.css están en la misma carpeta que .jsx
  2. Docusaurus debe estar configurado para CSS Modules (lo está por defecto)
  3. Si persiste, ve a docusaurus.config.js y busca "cssModules"


PROBLEMA: "useRealData is undefined"
SOLUCIÓN: Verifica que archivo hooks/useRealData.js existe en components/GaleriaForense/hooks/


PROBLEMA: "Tooltips no funcionan en mobile"
SOLUCIÓN: Es intencional. En <480px, usa click/tap en lugar de hover.

Una vez integrado y funcionando:

1. PERSONALIZACIÓN
   - Ajusta alertas/anotaciones en cada componente si necesitas
   - Cambia fuentes si lo requiere tu universidad
   - Adapta estructura si necesitas más/menos gráficos

2. DATOS REALES
   - Si consigues JSONs reales, colócalos en static/data/processed/
   - Los componentes cargarán automáticamente
   - El fallback hardcodeado sigue siendo backup

3. DOCUMENTACIÓN
   - Agrega contexto académico en cada sección
   - Cita fuentes (ICAI, REE, Gobierno de España)
   - Incluye tablas de referencia del TFG

4. PRINT/PDF
   - Docusaurus soporta print-to-PDF nativo
   - Los gráficos se renderizan correctamente en PDF
   - Usa Cmd+P (Mac) o Ctrl+P (Windows) en la página

5. PERFORMANCE
   - Si tienes >100 eventos por gráfico, ya están memoized
   - Lighthouse debería dar 90+ en performance
   - Si baja, revisa Console por memory leaks

6. ACCESIBILIDAD
   - Todos los componentes cumplen WCAG 2.1 AA
   - Usa axe DevTools para verificar finales
   - Screen readers funcionan (ARIA labels completos)
