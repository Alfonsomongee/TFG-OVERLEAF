INSTRUCCIONES:

1. Copiar archivos React:
   $ cp GalleryForensic.jsx src/components/GalleryForensic/
   $ cp GalleryForensic.module.css src/components/GalleryForensic/

2. Procesar datos:
   $ node process-28a-data.js
   
   Esto generará automáticamente en /data-processed/:
   - 28A_inertia.json
   - 28A_ics_violations.json
   - 28A_demand.json
   - 28A_voltage_manoeuvres.json
   - 28A_topology_manoeuvres.json
   - gallery-index.json

3. Copiar archivos procesados:
   $ cp data-processed/* src/data/processed/

PERSONALIZACIÓN - CÓMO MODIFICAR DATOS
═════════════════════════════════════════

A. Agregar más tablas a una categoría:

En GalleryForensic.jsx, encontrar:

```javascript
{
  id: 'frequency-stability',
  name: 'Estabilidad de Frecuencia',
  tables: [
    { /* tabla existente */ },
    // AGREGAR AQUÍ:
    {
      id: 'rocof-analysis',
      name: 'RoCoF Máximo por Período',
      source: 'Cálculos PSCAD',
      type: 'table',
      data: [
        { period: '12:32:57→12:33:29', rocof_hz_per_s: -1.85, trigger: 'Granada trip' },
        // ...
      ],
      columns: ['period', 'rocof_hz_per_s', 'trigger'],
    }
  ]
}
```

B. Cambiar colores de categorías:

En GalleryForensic.jsx, línea ~45:

```javascript
color: 'hsl(190 100% 60%)'  // CAMBIAR ESTE HSL
```

Opciones recomendadas:
- Azul (estabilidad): hsl(190 100% 60%)
- Naranja (alerta): hsl(38 100% 56%)
- Rojo (peligro): hsl(0 75% 56%)
- Morado (técnico): hsl(270 80% 55%)


C. Agregar nuevos gráficos:

1. Crear JSON con datos en src/data/processed/:
   ```json
   {
     "data": [
       { "datetime": "2025-04-28T12:30:00Z", "value": 50.0 },
       { "datetime": "2025-04-28T12:31:00Z", "value": 49.8 },
     ]
   }
   ```

2. Agregar tabla en GalleryForensic.jsx:
   ```javascript
   {
     id: 'frequency-timeseries',
     name: 'Frecuencia en tiempo real',
     source: 'Simulación PSCAD / Mediciones REE',
     type: 'chart',
     chartData: [...],  // O cargar desde JSON
     chartConfig: {
       dataKey: 'frequency_hz',
       stroke: 'hsl(190 100% 60%)',
       referenceLines: [
         { value: 50, label: 'Nominal', stroke: 'hsl(140 70% 50%)' },
         { value: 47.5, label: 'Umbral UFLS', stroke: 'hsl(38 100% 56%)' },
       ],
     },
   }
   ```

TROUBLESHOOTING
═════════════════

❌ "GalleryForensic is not exported"
   → Verificar que está registrado en MDXComponents.js

❌ "Cannot find module 'recharts'"
   → npm install recharts

❌ Tablas no se muestran
   → Verificar que los JSONs están en src/data/processed/
   → Revisar console.log de errores en browser

❌ Estilos no aplican
   → Verificar que .module.css está en la misma carpeta
   → Revisar que el import en JSX sea: import styles from './...'

❌ Gráficos se ven pequeños
   → En .module.css, ajustar altura en .chartContainer

gallery-index.json:
  Índice de galerías con metadatos
  Estructura: categorías → tablas → propiedades


NOTAS TÉCNICAS
═══════════════

• CSS Module: GalleryForensic.module.css NO contiene resets globales
  → Compatible con tu TFG sin conflictos de estilo

• BrowserOnly: Envuelve el componente para Docusaurus SSR
  → No genera errores en build, renderiza en cliente

• Recharts: Usa ResponsiveContainer para adaptarse a pantallas
  → No necesita ajustar altura manualmente (salvo mobile)

• Formato de datos: JSON plano (sin gzip)
  → Fácil de validar, depurar y versionar

PREGUNTAS FRECUENTES
═══════════════════════

P: ¿Se actualiza automáticamente con nuevos datos?
R: No. Necesitas ejecutar process-28a-data.js cada vez que actualices
   tus archivos TABLAS.txt o JSON de demanda.

P: ¿Puedo agregar datos de Portugal / Francia?
R: Sí. El processor actualmente filtra por 'Península' pero puedes
   modificar las líneas ~70 para incluir otros dominios.

P: ¿Qué tan grandes pueden ser los JSONs?
R: Hasta 5 MB sin problemas. El processor está diseñado para comprimir
   automáticamente (1083 puntos en lugar de 86,400).

P: ¿Es accesible (a11y)?
R: Parcialmente. El componente tiene:
   ✓ ARIA labels en tablas
   ✓ Contraste >4.5:1 WCAG AAA
   ✗ Falta: keyboard navigation en gráficos Recharts

P: ¿Funciona offline?
R: Sí, si cargas los JSONs localmente (no desde API).
