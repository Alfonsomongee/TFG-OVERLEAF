📈 Gráfica – Reducción del umbral de inercia crítica en ERCOT (con FFR)
Justificación: El capítulo cita un caso real de ERCOT (Texas) donde la integración de 450 MW de respuesta rápida de frecuencia (FFR) redujo el umbral de inercia crítica de 100.000 MW·s a 88.000 MW·s. Una gráfica de barras es ideal para visualizar este impacto.

Formato: Serie para Recharts (array de objetos con dos barras)

json
[
  { "escenario": "Sin FFR", "inercia_critica_mw_s": 100000, "descripcion": "Umbral base antes de integrar FFR" },
  { "escenario": "Con FFR (450 MW)", "inercia_critica_mw_s": 88000, "descripcion": "Tras integrar 450 MW de respuesta rápida de frecuencia" }
]
Nota: Esta gráfica puede representarse como BarChart o ComposedChart en Recharts. La reducción es del 12%, un dato muy visual para reforzar la tesis de que la electrónica de potencia bien diseñada puede sustituir parcialmente la inercia síncrona.
