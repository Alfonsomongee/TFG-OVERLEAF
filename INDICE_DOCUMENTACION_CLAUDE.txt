# ÍNDICE DE DOCUMENTACIÓN DISPONIBLE (CONTEXTO PARA CLAUDE)

Este archivo enumera los documentos `.txt` presentes en el repositorio, diseñados para proporcionar contexto sobre el Trabajo de Fin de Grado (TFG), su arquitectura, datos forenses y directrices de diseño. Puedes solicitar la lectura de cualquiera de ellos si necesitas profundizar en algún aspecto para el desarrollo del Dashboard o componentes de Docusaurus.

## 1. Archivos de Contexto y Directrices (Core)
- **`CONTEXTO_CLAUDE.txt`**: Documento fundamental. Contiene el "System Prompt" maestro, la narrativa del TFG, el tono técnico requerido y las directrices estéticas estrictas (estilo Cyber-Forense / SCADA, paletas de colores, prohibición de estilo "juguete" o Tailwind estándar).
- **`PROYECTO MEJORA DOCUSAURUS.txt`**: Detalla la estrategia de migración del proyecto desde un Dashboard interactivo en Streamlit hacia una página de documentación estática en Docusaurus con componentes React incrustados de alto impacto visual.

## 2. Archivos de Datos Técnicos y Forenses
- **`DATOS_FORENSES_28A.txt`**: Contiene la cronología exacta, métricas telemetricas y narrativas técnicas (Administración vs. Sector Generador vs. ENTSO-E) del apagón del 28 de abril en el sistema ibérico. Es crucial para el contenido de las visualizaciones.
- **`ESTRUCTURA_JSONS_28A.txt`**: Define la estructura y el esquema de los archivos JSON utilizados para inyectar los datos del apagón en los gráficos interactivos (Recharts, animaciones SVG).
- **`RESUMEN/CAPITULO_RESUMEN_DE_CIFRAS.txt` / `ResumenEjecutivo.txt`**: Contienen las cifras de alto nivel del colapso (15.2 GW de generación destruida, 60 millones de afectados, 7.9% de interconexión) ideales para tarjetas de métricas o KPIs.

## 3. Contenido Académico del TFG
- **`TFG_TEXTO_COMPLETO.txt` / `TFG_COMPLETO.txt`**: Contienen el cuerpo de texto académico completo del TFG (desde la introducción hasta la conclusión). Sirven de base para extraer párrafos, descripciones o referencias precisas.
- **`GLOSARIO TECNICO.txt` / `raw_terms_defs.txt`**: Contienen todas las definiciones técnicas (Tap-Lag, UFLS, IBR, Inercia, etc.) utilizadas en los tooltips interactivos de Docusaurus.
- **`TABLAS POR CAPITULOS.txt`**: Recopilación de todas las tablas de datos, estadísticas comparativas y matrices de responsabilidad formateadas originalmente en Markdown, listas para ser convertidas en componentes React.

## 4. Archivos de Código, Estilos y UI
- **`CONTEXTO_Y_CODIGO_DASHBOARD.txt`**: Snapshot del código antiguo del dashboard original en Streamlit (app.py). Útil si necesitas entender la lógica matemática o el comportamiento de una métrica que se está portando a React.
- **`src/components/CineMode/MODO CINE.txt` / `CINEIMPROVED.txt`**: Archivos que contienen la lógica completa en JSX y CSS Modules de las animaciones SVG del "Modo Presentación/Cine" para estudiar cómo se implementan los estilos aislados e interactivos en el proyecto.

## 5. Registros de Desarrollo y Tareas
- **`CAMBIOSDEFINITIVOS.txt` / `SEMANA2.txt` / `SEMANA 3.txt`**: Bitácoras que contienen listas de bugs resueltos, feedback del autor, errores pasados a evitar y tareas pendientes.
- **`informe_revision.txt`**: Notas de revisión académica sobre el contenido y la narrativa técnica.
