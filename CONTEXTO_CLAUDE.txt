CONTEXTO GENERAL DEL PROYECTO TFG: APAGÓN IBÉRICO DEL 28-A
====================================================================

Hola Claude, a continuación te presento un contexto detallado del proyecto en el que estamos trabajando, seguido de la configuración del sitio, un fragmento del índice de búsqueda y dos simuladores interactivos clave.

--- INTRODUCCIÓN Y NATURALEZA DEL TRABAJO ---
Este es un Trabajo de Fin de Grado (TFG) interactivo titulado "Análisis Forense del Apagón Ibérico del 28 de Abril de 2025 (28-A)".
A diferencia de los TFGs tradicionales en formato PDF estático, este proyecto está desarrollado como un sitio web interactivo en Docusaurus con un diseño "ciber-forense" premium (modo oscuro, acentos cian y ámbar, y animaciones de terminal).

El 28-A representa un apagón general de la península ibérica (España y Portugal) que dejó sin suministro a unos 57 millones de personas.
El análisis del trabajo compara tres visiones periciales en conflicto sobre las causas raíz:
1. La visión de la Administración y el Operador del Sistema (REE): centrada en el cumplimiento regulatorio (falta de absorción de reactiva por las plantas renovables, según Procedimiento de Operación P.O. 7.4).
2. La visión del sector de la Generación (Informe IIT-ICAI / AELEC / Compass Lexecon): apunta a fallos de observabilidad de REE en la red de 220 kV y a la maniobra de mallado (meshing) que indujo sobretensiones capacitivas por efecto Ferranti, desencadenando el fenómeno "Tap-Lag".
3. La visión de ENTSO-E (el gestor europeo): analiza las oscilaciones inter-área síncronas continentales y la fragilidad del Criterio N-1 frente a dinámicas ultrarrápidas de inversores en redes con alta penetración renovable y baja inercia síncrona.

--- ARQUITECTURA TÉCNICA DE LA WEB ---
- Framework: Docusaurus (React + MDX).
- Buscador y Chatbot: Usamos un chatbot RAG local. En el cliente, consume una biblioteca de búsqueda liviana (minisearch) cargada con un índice jerárquico estático ('static/chunks.json'). Cuando el usuario hace una pregunta, minisearch extrae los fragmentos más relevantes y los envía junto con el prompt del sistema al API /api/chat que llama a DeepSeek (v3/r1) para generar la respuesta.
- Gráficas y Simuladores: Componentes React personalizados con Recharts y animaciones SVG interactivas (sin Tailwind, usando CSS Modules puros).

function TapLagSequenceInner({}) {
  const lang = useDocLang();
  const [activeStep, setActiveStep] = useState(0);
  const steps = useMemo(() => getSteps(lang), [lang]);
  const step  = steps[activeStep];
  const isEs  = lang === 'es';

  const prefersReduced = useMemo(
    () => typeof window !== 'undefined' &&
      window.matchMedia('(prefers-reduced-motion: reduce)').matches,
    [],
  );

  const prev = useCallback(() => setActiveStep(s => Math.max(0, s - 1)), []);
  const next = useCallback(() => setActiveStep(s => Math.min(steps.length - 1, s + 1)), [steps.length]);

  const phaseColor = step.cascade ? C.critical : step.ansi59 ? C.critical : step.id >= 3 ? C.warning : C.normal;

  return (
    <div style={{ fontFamily: 'monospace' }}>

      {/* Título del paso */}
      <div style={{
        display: 'flex', justifyContent: 'space-between', alignItems: 'flex-start',
        marginBottom: '0.75rem', flexWrap: 'wrap', gap: '0.5rem',
      }}>
        <div>
          <span style={{
            fontSize: 10, color: phaseColor, fontWeight: 700,
            letterSpacing: '0.1em', textTransform: 'uppercase',
          }}>
            {isEs ? `Paso ${step.id} de ${steps.length}` : `Step ${step.id} of ${steps.length}`}
            {' · '}{step.time}
          </span>
          <h4 style={{ margin: '4px 0 0', fontSize: 15, color: phaseColor }}>
            {step.title}
          </h4>
          <p style={{ margin: '3px 0 0', fontSize: 12, color: 'var(--ifm-color-emphasis-600)', lineHeight: 1.5 }}>
            {step.subtitle}
          </p>
        </div>

        {/* Controles */}
        <div style={{ display: 'flex', gap: '0.4rem', alignItems: 'center' }}>
          <button
            onClick={prev}
            disabled={activeStep === 0}
            aria-label={isEs ? 'Paso anterior' : 'Previous step'}
            style={{
              padding: '0.35rem 0.75rem',
              background: 'transparent',
              border: `1px solid ${activeStep === 0 ? C.border : phaseColor}`,
              borderRadius: 4, color: activeStep === 0 ? C.dim : phaseColor,

              fontFamily: 'monospace', fontSize: 13,
              opacity: activeStep === 0 ? 0.4 : 1,

            disabled={activeStep === steps.length - 1}
            aria-label={isEs ? 'Paso siguiente' : 'Next step'}
            style={{
              padding: '0.35rem 0.75rem',
              background: activeStep < steps.length - 1 ? `${phaseColor}22` : 'transparent',

              fontFamily: 'monospace', fontSize: 13,
              opacity: activeStep === steps.length - 1 ? 0.4 : 1,
            }}
          >
            →
          </button>
        </div>
      </div>

      {/* Barra de progreso clicable */}
      <div style={{
        display: 'flex', gap: '3px', marginBottom: '0.75rem',
      }}
        role="tablist"
        aria-label={isEs ? 'Pasos del mecanismo Tap-Lag' : 'Tap-Lag mechanism steps'}

        background: C.bg,
        borderRadius: 10,

        transition: 'border-color 0.3s ease',

      </div>
