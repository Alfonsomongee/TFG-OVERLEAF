# PROYECTO: DASHBOARD FORENSE 28-A - ANÁLISIS DE VIABILIDAD Y ESTADO

## CONTEXTO GENERAL

Estamos desarrollando un dashboard forense interactivo en Python + Streamlit 
para analizar el apagón ibérico del 28 de abril de 2025, comparándolo con 
el estado actual en tiempo real del sistema eléctrico español.

Tecnología:
- Frontend: Streamlit + Plotly
- Backend: Python 3.9+
- APIs: ESIOS (REE) + ENTSO-E
- IA: Ollama mistral:7b + ChromaDB
- Storage: SQLite + ChromaDB

#### 2. fetcher_entsoe.py (450 líneas)
✓ Cliente ENTSO-E con retry strategy

✓ Cross-border physical flows implementado

#### 3. inercia_calculator.py (320 líneas)
✓ Swing equation: H = (ΔP · f₀) / (2 · RoCoF · S_base)
✓ Cálculos de inercia con confianza bayesiana
✓ Rolling window analysis (ventana móvil 60 min)
✓ Datos históricos 28-A pregenerados

**Parámetros:**
- SYSTEM_POWER_BASE = 20,000 MW
- SYSTEM_FREQUENCY_NOMINAL = 50 Hz
- H_nominal: 8s, H_critical: <4s

#### 4. rocof_detector.py (350 líneas)
✓ RoCoF detection: dF/dt
✓ Tres métodos: simple, Savitzky-Golay (DEFAULT), Butterworth
✓ Event detection automático
✓ Clasificación por umbral

**Métodos:**
- Simple: Diferencia finita (rápido, ruidoso)
- Savitzky-Golay: Polinomio local (ÓPTIMO)
- Butterworth: Low-pass filter (suavizado)

**Umbrales:**
- |RoCoF| < 0.2: NOMINAL
- 0.2-0.5: ALERT_LOW
- 0.5-1.0: ALERT_HIGH
- >1.0: UFLS_TRIGGER

#### 5. analyzer.py (550 líneas)
✓ Risk Score polinómico: 50% FSM + 35% RoCoF + 15% Damping
✓ Análisis causal condicional (5 heurísticas IF-THEN)
✓ Comparativa vs 28-A histórico
✓ Generación de narrativa automática
✓ Proyecciones probabilísticas

**Fórmula Risk:**
Risk = w₁·(1-fsm/2.0)·100 + w₂·(|rocof|/1.0)·100 + w₃·(1-damp)·100

**Análisis causal:**
- Si H < 4s AND solar > 50% → Riesgo inestabilidad
- Si |RoCoF| > 0.6 AND H > 5 → Pérdida generación
- Si freq < 49.5 AND RoCoF < -0.3 → Trayectoria colapso

#### 6. rag_engine.py (650 líneas)
✓ ChromaDB: BD vectorial de documentos TFG
✓ Ollama: LLM local mistral:7b
✓ RAG pipeline: Recuperación semántica + generación
✓ Cache en memoria (top 30 preguntas)
✓ Fallback cuando no hay matches (similitud < 0.65)

**Configuración Ollama:**
- Model: mistral:7b
- Temperature: 0.1 (determinístico)
- Timeout: 30s
- System prompt: Imperativo (SOLO basado en TFG)

#### 7. visualizaciones.py (550 líneas)

✓ Tema forense: #0B0E14 (bg), #151A22 (panel)
✓ Colores WCAG AA compatible
✓ Interactividad: hover, zoom, pan nativo Plotly

#### 8. app.py (400 líneas)
✓ Orquestador Streamlit

✓ Caching de clientes (@st.cache_resource)

```json
  }

```

**Características técnicas:**
- Eje Y: Tensión p.u. (por unidad)
- Bandas: Verde (nominal ±5%), amarillo (±8%), rojo (±12%)
- Anotación: "Disparo transformer Granada 12:32:57 → -355 MW"
- Líneas múltiples (una por nudo)

**Impacto:** Mostrar que la SOBRETENSIÓN fue el precipitador, NO la frecuencia baja

#### Gráfica 6: Estabilidad Angular del Rotor (Rotor Angle δ)
**Física:** Ángulo del rotor de generadores vs referencia. 
El "efecto látigo" (whip effect) causó pérdida de sincronismo en Francia.

**Datos necesarios:**
```json
{
  "28a": {
    "generator_1": [-2.5, -3.1, -4.2, ..., -15.8],
    "generator_2": [-1.8, -2.4, -3.5, ..., -14.2],
    "center_of_inertia": [-2.1, -2.7, -3.8, ..., -15.0]
  }
}
```

**Análisis modal incluido:**
δ(t) = A_NS·sin(ω_NS·t + φ_NS) + A_EO·sin(ω_EO·t + φ_EO)
Modos:

Modo Norte-Sur (oscillation inter-area): ~0.6-0.8 Hz
Modo Este-Oeste: ~0.3-0.5 Hz
Damping factor: 0.1-0.3 (crítico si < 0.05)


**Técnica:** FFT para descomponer modos dominantes

#### Gráfica 7: Flujos de Energía (Sankey Animado o SVG D3.js)
**Concepto:** Flujo de potencia entre regiones a lo largo del tiempo.
Visualizar cómo se "apagan" la cascada.

**Estructura:**
Francia ──→ España ──→ Portugal
│
├──→ Marruecos
└──→ Italia

**Datos necesarios:**
```json
{
  "12:00:00": {

  }

```

**Animación:** Botón PLAY que secuencia timeline y ancha/color cambio dinámico
