TAREA 1: Optimización de diaapagon.png (CRÍTICO)
El archivo /static/img/diaapagon.png pesa 8,8 MB.
Con Wi-Fi de congreso puede tardar 15-20 segundos en cargar.
Eso destruye la primera impresión de la ponencia.

Ejecutar en la terminal del proyecto:
  npx sharp-cli -i static/img/diaapagon.png \
    -o static/img/diaapagon-1920.avif \
    --format avif --quality 50 --width 1920
  
  npx sharp-cli -i static/img/diaapagon.png \
    -o static/img/diaapagon-1920.webp \
    --format webp --quality 75 --width 1920
  
  npx sharp-cli -i static/img/diaapagon.png \
    -o static/img/diaapagon-960.avif \
    --format avif --quality 50 --width 960
  
  npx sharp-cli -i static/img/diaapagon.png \
    -o static/img/diaapagon-960.webp \
    --format webp --quality 75 --width 960

Si sharp-cli no está instalado: npm install -g sharp-cli

Resultado esperado:
  diaapagon-1920.avif → ~120 KB (reducción del 98%)
  diaapagon-1920.webp → ~180 KB

Luego localizar dónde se usa diaapagon.png en el proyecto
(puede ser en MDX, en JSX o en CSS) y reemplazar con:

  <picture>
    <source type="image/avif"
      srcSet="/img/diaapagon-960.avif 960w,
              /img/diaapagon-1920.avif 1920w"
      sizes="(max-width: 768px) 100vw, 1920px" />
    <source type="image/webp"
      srcSet="/img/diaapagon-960.webp 960w,
              /img/diaapagon-1920.webp 1920w"
      sizes="(max-width: 768px) 100vw, 1920px" />
    <img
      src="/img/diaapagon-1920.webp"
      alt="Mapa de la Península Ibérica durante el apagón del 28 de abril de 2025"
      width="1920" height="1080"
      loading="eager"
      fetchpriority="high" />
  </picture>

TAREA 2: Activar PWA offline (CRÍTICO PARA EL CONGRESO)
El ponente necesita poder cargar el sitio la noche anterior
en el hotel y que funcione sin red al día siguiente.

En docusaurus.config.js, añadir en el array `plugins`:

  ['@docusaurus/plugin-pwa', {
    debug: false,
    offlineModeActivationStrategies: [
      'appInstalled',
      'standalone',
      'queryString',
    ],
    pwaHead: [
      { tagName: 'link', rel: 'manifest', href: '/manifest.json' },
      { tagName: 'meta', name: 'theme-color', content: '#0a0a0a' },
    ],
    injectManifestConfig: {
      maximumFileSizeToCacheInBytes: 5 * 1024 * 1024,
      globPatterns: ['**/*.{js,css,html,svg,woff2,webp,avif}'],
    },
  }],

Si el plugin no está instalado:
  npm install @docusaurus/plugin-pwa

Instrucción para el ponente (añadir a README o mandar por email):
  "Abrir https://tfg-overleaf.vercel.app/?offlineMode=true
   en Chrome la noche antes. Esperar 30 segundos.
   Verificar en DevTools → Application → Service Workers
   que el estado es 'activated and running'.
   A partir de ese momento el sitio funciona sin conexión."

TAREA 3: Lighthouse CI — medir el estado actual
Ejecutar antes y después de las optimizaciones:
  npx lighthouse https://tfg-overleaf.vercel.app \
    --output=json --output-path=./lighthouse-report.json \
    --chrome-flags="--headless"

Reportar los valores de:
  - LCP (Largest Contentful Paint) — objetivo: <2,5 s
  - CLS (Cumulative Layout Shift) — objetivo: <0,1
  - INP (Interaction to Next Paint) — objetivo: <200 ms
