### Tarea C3: AbortController en EntsoeCharts y EsiosCharts
**Prioridad:** 🔴 CRÍTICA  
**Tiempo estimado:** 30 min  
**Archivos:** Todos los `.jsx` en `src/components/EntsoeCharts/` (14) y `src/components/EsiosCharts/` (8)

**Instrucciones:**
Para CADA componente que tenga un `useEffect` con `fetch()`, aplica este patrón:

```jsx
useEffect(() => {
  const controller = new AbortController();
  
  fetch(url, { signal: controller.signal })
    .then(res => res.json())
    .then(data => {
      if (!controller.signal.aborted) {
        setData(data);
      }
    })
    .catch(err => {
      if (err.name !== 'AbortError') {
        console.error('Error fetching data:', err);
        setError(err);
      }
    });

  return () => controller.abort();
}, []);
```

**CASO ESPECIAL:** `ActualGenerationChart.jsx` (líneas 27-31) hace 5 fetches sin `.catch()`. Usa `Promise.all` con un solo AbortController:

```jsx
useEffect(() => {

    fetch(url1, opts).then(r => r.json()),
    fetch(url2, opts).then(r => r.json()),
    fetch(url3, opts).then(r => r.json()),
    fetch(url4, opts).then(r => r.json()),
    fetch(url5, opts).then(r => r.json()),
  ])
    .then(([d1, d2, d3, d4, d5]) => {
      if (!controller.signal.aborted) {
        // set states
      }
    })
    .catch(err => {
      if (err.name !== 'AbortError') {
        console.error('Error:', err);
        setError(err);
      }
    });

  return () => controller.abort();
}, []);
```
