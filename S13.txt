PROPÓSITO PEDAGÓGICO:
El mecanismo causal del 28-A no fue la falta de inercia sino el
colapso de tensión por déficit reactivo en barras colectoras IBR
con SCR bajo. La curva P-V (curva nariz) es la herramienta
canónica para visualizar este mecanismo. El tribunal de Comillas
o Sevilla espera ver este diagrama.

MODELO FÍSICO (sistema de 2 nudos: SLACK — impedancia — carga):

  V² - (E²/2 - P·R - Q·X) · (2/1) ±
  √[(E²/2 - P·R - Q·X)² - (P²+Q²)(R²+X²)] = 0

donde Q = P·tan(φ), φ = arccos(cosPhi).

El SCR escala la impedancia equivalente vista desde el IBR:
  Xeq = X_base / SCR
  Req = R_base / SCR

Barrido de P desde 0 hasta el nose point (discriminante = 0).
El nose point es el punto de máxima cargabilidad: más allá,
el sistema colapsa (rama inferior inestable).

FUNCIÓN DE CÁLCULO (crear en utils/computePVCurve.js):

export function computePVCurve({
  E = 1.0,          // tensión en la fuente (p.u.)
  X_base = 0.5,     // reactancia base (p.u.)
  R_base = 0.05,    // resistencia base (p.u.)
  cosPhi = 0.95,    // factor de potencia de la carga
  SCR = 3.0,        // Short Circuit Ratio
  step = 0.002      // resolución del barrido
}) {
  const tanPhi = Math.tan(Math.acos(cosPhi));
  const Xeq = X_base / SCR;
  const Req = R_base / SCR;
  const upper = [], lower = [];
  let noseP = 0, noseV = 0;

  for (let P = 0; P <= 5; P += step) {
    const Q = P * tanPhi;
    const b = E*E - 2*P*Req - 2*Q*Xeq;
    const disc = (b*b/4) - (P*P + Q*Q)*(Req*Req + Xeq*Xeq);
    if (disc < 0) { noseP = P - step; break; }
    const Vplus  = Math.sqrt(b/2 + Math.sqrt(disc));
    const Vminus = Math.sqrt(Math.max(0, b/2 - Math.sqrt(disc)));
    upper.push({ P: parseFloat(P.toFixed(3)), V: parseFloat(Vplus.toFixed(4))  });
    lower.unshift({ P: parseFloat(P.toFixed(3)), V: parseFloat(Vminus.toFixed(4)) });
    if (Math.abs(Vplus - Vminus) < 0.02) {
      noseV = (Vplus + Vminus) / 2;
    }
  }
  const margin = noseP - 0.82; // 0.82 p.u. = operación típica pre-28A
  return { upper, lower, noseP, noseV, margin };
}
