CÓDIGO MUERTO PROBABLE
================================================================================

Tipos de código muerto:

1. CONDICIONES NUNCA ALCANZADAS:
   Ejemplo:
     if (process.env.NODE_ENV === 'production' && false) {
       // código nunca ejecutado
     }

2. VARIABLES SIN USAR:
   Ejemplo:
     const unused = getData();  // nunca se usa 'unused'

3. IMPORTS SIN USAR:
   Ejemplo:
     import { someFunction } from './utils';  // nunca se llama

4. FUNCIONES SIN LLAMADAS:
   Ejemplo:
     function helperFunction() { ... }  // nunca llamada

5. RAMAS CONDICIONALES:
   Ejemplo:
     try { ... } catch (e) { /* empty */ }  // catch nunca entra

HERRAMIENTA PARA ENCONTRAR:
  - ESLint regla: no-unused-vars
  - IDE: "Find usages" para cada export

================================================================================
POTENCIALES REFACTORINGS
================================================================================

1. EXTRAER COMPONENTES BASE:
   Patrón: Muchos componentes similares (charts, cards)
   Propuesta: Crear CardBase, ChartBase, etc.
   Beneficio: Reducir duplicación

2. CONSOLIDAR CSS:
   Patrón: custom.css muy grande (3773 líneas)
   Propuesta: Dividir en módulos (typography.css, components.css, etc.)
   Beneficio: Más mantenible, árbol de CSS shaking

3. CENTRALIZAR COLORES:
   Patrón: Variables CSS pero algunos hardcodean colores
   Propuesta: Forzar uso de variables globales
   Beneficio: Cambio de tema más fácil

4. CREAR UTILIDADES:
   Patrón: Estilos inline repetidos
   Propuesta: Clases Tailwind o utilidades CSS
   Beneficio: Menos código duplicado

5. MIGRATIONS DE VERSIONES:
   Propuesta: Plan para Docusaurus 3.0 + React 18
   Pasos:
     1. Update React 17 → 18
     2. Test todos los componentes
     3. Update Docusaurus 2.4 → 3.0
     4. Fix breaking changes en swizzles
     5. Deprecate componentes antiguos
