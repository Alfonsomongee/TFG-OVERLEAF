CHATBOT RAG
================================================================================

Configuración detectada:

API endpoint:
  /api/chat.js (serverless function)
  Ruta: api/chat.js (en raíz, no en src/)

Propósito:
  Chatbot RAG (Retrieval-Augmented Generation)
  Usa minisearch + chunks.json para buscar contexto
  Llamadas a Anthropic Claude API para generar respuestas

Datos incluidos en función (via vercel.json):
  {
    includeFiles: "{static/*.json,node_modules/minisearch/dist/**/*}"
  }

Archivos empaquetados:
  - static/data/chunks.json (chunks de documentación)
  - static/data/search-index.json (índice de búsqueda)
  - node_modules/minisearch/ (librería de búsqueda)

Propósito arquitectural:
  - Sin backend externo (everything bundled)
  - Búsqueda local + LLM remoto
  - Genera respuestas contextualizadas al documento

POTENCIAL CHATBOT - FLUJO DE INTERACCIÓN
================================================================================

Flujo probable si chatbot existe:

1. Usuario hace click en botón flotante
2. Panel se abre (animación slide/fade)
3. Welcome message muestra contexto (capítulo actual?)
4. Usuario escribe pregunta
5. JavaScript:
   - Busca contexto en chunks.json (minisearch)
   - Envía a /api/chat con {query, context, lang}
6. Backend:
   - Llama Anthropic API con prompt + contexto
   - Retorna respuesta generada
7. UI:
   - Muestra respuesta con streaming (si es posible)
   - Guarda conversación en sessionStorage
8. Usuario puede:
   - Hacer más preguntas
   - Copiar respuesta
   - Compartir enlace

LIMITACIONES:
  - Sin persistencia (sesión solo)
  - Sin historial multi-usuario
  - Limitado a contexto del documento actual

POTENCIALES PROBLEMAS
================================================================================

1. **Chatbot no funciona**
   - API key de Anthropic no configurada
   - chunks.json vacío o mal formateado
   - CORS headers incorrectos

2. **Tooltips no aparecen**
   - remark-auto-glossary-links no instalado
   - CSS de tooltip oculto
   - Z-index conflict

3. **Chat widget interfiere con contenido**
   - Z-index conflicto con elementos otros
   - Mobile layout roto (chat cubre botones)
   - Performance issue (rerender frecuente)

4. **Accesibilidad**
   - Chat no usable con keyboard
   - Screen reader no anuncia new messages
   - Focus trap implementado mal
