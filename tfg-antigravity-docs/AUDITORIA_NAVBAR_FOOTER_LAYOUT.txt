  --fs-h3:        clamp(1.75rem, 1.3rem + 1.8vw, 2.4rem)

TOGGLE ZEN-MODE
================================================================================

Script inline en <head> (docusaurus.config.js, headTags):

Funcionalidad:
  1. Lee localStorage.zen-mode
  2. Si está true o no definido, añade class 'zen-mode' a <html>
  3. Ejecuta ANTES del render (evita flash)

CSS correspondiente (en custom.css):
  html.zen-mode { /* estilos para modo zen */ }
  → Probablemente: oculta navbar/sidebar, maximiza contenido

Propósito:
  Permitir lectura sin distracciones
  Estado persiste en localStorage

================================================================================
RESPONSIVE BREAKPOINTS
================================================================================

Docusaurus usa breakpoints de CSS estándar:
  sm: 320px
  md: 768px (sidebar → collapse en mobile)
  lg: 1024px
  xl: 1216px

COMPORTAMIENTO ESPERADO:
  < 768px: Sidebar oculto, drawer/hamburger menu
  >= 768px: Sidebar visible en desktop

Uso en custom.css: media queries con (min-width:) y (max-width:)
