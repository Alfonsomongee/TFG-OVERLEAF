  <AnnexKeyQuestion>
    2025年4月28日上午，预测需求、发电组合和半岛系统的运行平衡如何制约可用的动态安全裕度？
  </AnnexKeyQuestion>

  <AnnexThesisBox>
    4月28日上午，半岛发电量充裕地满足了需求，但发电组合的构成——82%来自基于逆变器的电源，仅11台同步机组并网——使系统处于全年最低惯量状态，且半岛南部的短路容量低于安全运行阈值。需求预测并未预示任何异常情况；预测值与实际值的偏差低于5%。脆弱性不在于可用功率的数量，而在于这些功率的动态特性。本附录确立了后续崩溃的必要——尽管非充分——条件。
  </AnnexThesisBox>

  <AnnexBlackoutRelevance>
    本附录记录了降低半岛系统惯量和短路容量至安全阈值以下的先前运行条件，为4月28日大停电创造了前提条件。
  </AnnexBlackoutRelevance>
