## 政府与REE的视角：多因素因果与违规行为

官方叙述将此次大停电定性为并非运行设计错误或调度操作直接后果的事件，而是一个多因素事件：低谷负荷、IBR大规模渗透以及私营主体不当技术行为的同时汇聚，超过了N−1准则的门槛。

REE对网格化操作的技术辩护值得精确审视。报告强调了批评中常被忽略的一个方面：初始振荡并未引起过电压，而是导致输电网节点电压下降。面对这一风险，控制中心执行了严格按规程操作——重新连接线路、耦合电抗器、与RTE协调将HVDC切换至PMODE1模式——承认这些操作“导致了电压上升”，但将其定性为必要措施。REE辩称，如果各主体履行了其监管义务，后续的任何电压升高本应是可吸收的。

核心论点将责任转移至发电厂：对850个最大发电设施的分析记录显示，约22%不符合根据第413/2014号皇家法令所要求的功率因数标准，尽管报告本身指出，部分不合规可能归因于低发电量下输电基础设施的电容效应。特别地，南部地区的一个火电厂不仅没有吸收感性无功功率，反而额外注入了容性无功功率。对于REE而言，私营发电厂的集体不作为使系统失去了抑制暂态过程所需的动态裕度。

关于惯量，REE明确排除了其作为实质原因的可能性：系统运行在$H = 2.3$秒，高于ENTSO-E推荐的2秒阈值<KeyFact id="inercia-28a" mode="callback">H = 2.3秒平均值 / 南部地区1.3秒 — 第2章</KeyFact>，并且“过电压波在任何情况下都会引发级联效应”，因为过电压条件持续到欧洲中部夏令时间12:33:23，与频率无关。

政府叙述呈现出明显的内部一致性，并指出了有据可查的违规行为。然而，它未能回应ICAI专家报告的两个论点：网格化注入的容性无功功率大小以及Tap-Lag现象导致运营商对220千伏网络不可观测——根据ICAI的说法，这两个因素使得无论发电厂的合规水平如何，崩溃都不可避免。

## 发电行业（ICAI / AELEC）的视角：过度网格化与不可避免的崩溃

与政府叙述相反，IIT-ICAI与Compass Lexecon和INESC TEC联合出具的专家意见正式将事件诊断为过电压崩溃：一种由无功功率吸收能力耗尽驱动的电压不稳定现象，其中REE自身的预防性操作充当了级联的主要向量。

批评的核心是定量的：ICAI模拟估计，网格化使卡莫纳节点的崩溃裕度从2964兆瓦缩减至1268兆瓦——减少了57%。<KeyFact id="mallado-ferranti" mode="callback">网格化物理原理与费兰梯效应 — 第3章，§阶段0</KeyFact>

![根据ICAI专家分析，卡莫纳400千伏节点的Q-V曲线](/figuras/fluctuaciones_tension_previas.png)

_图E2 — 卡莫纳400千伏节点的电压稳定性Q-V曲线（ICAI专家分析）。该图量化了网格化操作导致的崩溃裕度缩减：从2964兆瓦降至1268兆瓦，减少了57%，专家意见将其定性为使崩溃在数学上不可避免的条件。来源：IIT-ICAI / Compass Lexecon._

ICAI数据（2.4 GVAr）与NREL独立分析数据（1.05 GVAr）之间的差异并未改变共同结论：两种情况下，容性注入都超过了系统剩余吸收能力，后者估计仅为3.3 GVAr，而通常为5.8 GVAr。

关于级联跳闸，发电行业驳斥了“不当跳闸”的定性，指出运营商可观测性的局限性。**Tap-Lag**现象将过电压放大至REE的SCADA不可见的220千伏网络。<KeyFact id="fase-2-taplag" mode="callback">Tap-Lag的完整物理机制 — 第3章，§阶段2</KeyFact> 格拉纳达基础设施的所有者确认其保护装置“设置正确，并在其连接点实际经历的电压下正常运行”。<KeyFact id="granada-disparo" mode="callback">格拉纳达根跳闸 — 第3章</KeyFact>

这个盲点使得REE和发电行业的叙述在技术上互不相容：没有对底层网络的可观测性，运营商无法纠正其看不见的问题，而发电厂也无法不对其确实看到的问题进行跳闸。因此，分歧不在于事实本身——而在于面对双方都承认的工具性局限时，责任的归属。

![12:32:56.993 CEST格拉纳达根跳闸的波形记录](/figuras/aluvion_alertas_sobretension_sur.png)

_图E3 — 格拉纳达根跳闸的波形记录（12:32:56.993 CEST）。波形显示A相集电侧电压约为145千伏（>1.10 p.u.），该阈值正确触发了过电压保护，但由于Tap-Lag效应，REE的SCADA无法看到，形成了运行盲点，使得预防性干预无法进行。来源：IIT-ICAI / AELEC._

第二条论证线索指向监管框架：改革前的P.O. 7.4要求IBR以固定功率因数运行，尽管其电力电子设备具备动态吸收或注入无功功率的能力，但该规定阻止了其使用。这一限制将82%的瞬时发电量排除在主动电压控制之外，将责任集中在少数可用的同步火电机组上。

根据专家意见，由此产生的定量失衡在数学上是无法解决的：在振荡和网格化的中心——南部地区，REE仅有0.2 GVAr的感性无功吸收能力，而由其自身操作引起的容性注入估计超过0.7 GVAr。

![根据IIT-ICAI，12:30 CEST南部地区无功功率平衡](/figuras/asimetria_balance_reactiva_sur.png)

_图E4 — 12:30 CEST南部地区无功功率平衡。该图记录了−0.6 GVAr的净赤字：仅有0.2 GVAr的感性吸收能力，而网格化操作引起的容性注入超过0.7 GVAr，ICAI专家意见将此条件定性为数学上无法解决。来源：IIT-ICAI / Compass Lexecon._

专家意见的结论指出了三个直接归因于运营商和监管机构的因素：使Q-V裕度饱和的网格化、因Tap-Lag导致的220千伏网络结构性不可观测性，以及阻止82%的发电机组参与动态电压控制的监管框架（P.O. 7.4）。

## 欧洲视角（ENTSO-E）：NC RfG的不足与同步系统的分离

ENTSO-E的专家小组提供了三者中最具结构性的视角。其核心论点拒绝将停电归因于可再生能源渗透本身：崩溃并非可再生能源发电过剩或主要惯性短缺的结果，而是电压分布控制框架局限性的结果。该事件揭示了可再生能源资产快速部署与规范其动态行为的电网准则部分过时之间的不对称性。

分析指出了一个基本的技术紧张关系：大多数脱网的设施拥有执行稳健电压控制所需的电力电子设备，但当时有效的西班牙法规禁止或未要求它们提供这种动态服务，迫使其根据第413/2014号皇家法令以静态功率因数运行。这种监管限制剥夺了系统本可以缓冲空载线路容性注入的分布式无功支持。

作为直接回应，ENTSO-E在其第二阶段报告中巩固了NC RfG 2.0的更新，该更新计划强制要求所有≥1兆瓦的非同步模块具备构网能力：

这种分离防止了容性崩溃和频率下降——RoCoF超过1.5赫兹/秒——拖垮法国系统和欧洲大陆其他地区。

## 解释性综合：三个治理断裂

比较性审查使我们能够超越各方之间的争议，形成二阶诊断：4月28日的大停电既非不可预测的“黑天鹅”，也非特定技术的失败，而是伊比利亚电力系统中同时存在的三个治理断裂的汇聚表现。

### 运行断裂：因果关系与责任

网格化作为触发因素（ICAI）和集体违规作为原因（REE/政府）的论点在技术层面并非相互排斥：两个因素都导致了缩小Q-V裕度的容性饱和。然而，它们在法律和经济层面的含义是相互排斥的。这种因果模糊性是在没有足够动态仪表的网络中运行的可预见结果：当系统在所有关键节点没有PMU，也没有实时电压稳定性计算工具时，事后重建不可避免地受到解释的影响。各方之间的默契共识——没有一份报告明确阐述——是监测架构既不足以实时管理事件，也不足以在事后明确解决它。

### 监管断裂：适用于21世纪电网的20世纪法规

ENTSO-E的立场表明，运营商和发电厂都在旨在治理的体系不适当的法规限制内行事。P.O. 7.4和第413/2014号皇家法令设计了一个针对以慢响应同步质量为主的网络的电压控制方案；将其应用于IBR渗透率达82%的网络，在控制工程术语中，相当于试图用为分钟级动态设计的调节器来稳定毫秒级响应的系统。这种不适当并非不为人知：P.O. 7.4的更新提案多年来一直处于监管审批过程中。政府报告本身承认，其生效本应是本可避免崩溃的最相关变化。从这个意义上说，4月28日的大停电是监管延迟的可衡量代价。

### 系统断裂：动态网络中的静态安全工具

关于静态N−1准则不足的普遍共识指向了一个超越伊比利亚案例的脆弱性。将系统评估为“正常”的潮流模型在数学上无法表示低惯量网络中的容性不稳定现象：它们不求解微分方程，不模拟逆变器控制回路的动态，也不实时计算Q-V裕度。崩溃的进展速度——从首次跳闸到电压降至零不到90秒——将现象置于任何人为干预的时间范围之外：当运营商意识到暂态过程的严重性时，系统已无法恢复。唯一可行的应对措施是通过实时动态安全分析进行结构性预防，其在欧洲区域协调中心的部署是ENTSO-E确定的最紧迫改革之一。

### 集中式范式的局限性

在这三个断裂之下，存在一个报告以零散方式处理的更深层次的紧张关系：集中式运行范式——一个运营商，对400千伏层面的可见性有限，通过离散开关电抗器管理电压，并通过小时级市场信号调度同步发电——是为同步质量提供自然阻尼、发电机在几秒内响应的网络设计的。在一个82%的发电量由毫秒级响应的逆变器组成、通过PLL自提供同步参考、其动态行为对400千伏SCADA不透明的网络中，该范式已达到其管理能力的极限。

4月28日不仅仅是一个停电案例研究：它标志着高电力电子渗透率系统中集中式调度模式的枯竭，以及21世纪欧洲电网新的分布式、实时控制架构的强制性起点。
