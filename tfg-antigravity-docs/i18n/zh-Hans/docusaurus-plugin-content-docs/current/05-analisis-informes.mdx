对四份关于4月28日大停电报告进行的交叉分析揭示了一种超越具体技术分歧的争议架构：针对同一事件序列，存在三种截然不同的机构视角，并直接产生法律、经济和监管层面的影响。本章将审视每种叙事的内在一致性、其经过验证的共识点以及不可调和的分歧。

## 政府与REE的视角：多因素因果关系与违规行为

官方叙事将此次大停电定性为并非运行设计错误或调度操作的直接后果，而是一个多因素事件：低谷需求、IBR大规模渗透以及私营主体不当技术行为的同时汇聚，超过了N-1准则的门槛。

REE对其合环操作的技术辩护值得精确审视。报告强调了一个在批评中经常被忽略的方面：初始振荡并未引起过电压，而是导致输电网节点电压下降。面对这一风险，控制中心执行了严格按规程操作——重新连接线路、耦合电抗器、与RTE协调将HVDC切换至PMODE1模式——同时承认这些操作“导致了电压上升”，但将其定性为必要措施。REE辩称，如果各主体履行了其监管义务，后续的任何电压升高本应是可吸收的。

核心论点将责任转移至发电机组：对850个最大发电设施的分析记录显示，约22%不符合根据第413/2014号皇家法令所要求的功率因数标准，尽管报告本身也指出，部分不合规可能归因于低发电量下输电基础设施的电容效应。具体而言，南部地区的一个火电厂不仅没有吸收感性无功功率，反而注入了额外的容性无功。对REE而言，私营发电厂的集体不作为使系统失去了抑制暂态过程所需的动态裕度。

关于惯量，REE明确排除了其作为根本原因的可能性：系统运行在$H = 2.3$ s，高于ENTSO-E建议的2 s阈值<KeyFact id="inercia-28a" mode="callback">H = 2.3 s 平均值 / 1.3 s 南部区域 — 第2章</KeyFact>，并且“过电压波在任何情况下都会引发级联效应”，因为过电压条件持续到欧洲中部夏令时间12:33:23，与频率无关。

政府叙事呈现出显著的内在一致性，并识别出有据可查的违规行为。然而，它未能回应ICAI专家报告的两个论点：合环操作注入的容性无功量级，以及由于Tap-Lag现象导致运营商对220 kV网络不可观测性——根据ICAI的说法，这两个因素使得无论发电厂的合规水平如何，崩溃都不可避免。

## 发电行业视角（ICAI / AELEC）：过度合环与不可避免的崩溃

与政府叙事相反，IIT-ICAI与Compass Lexecon和INESC TEC联合出具的专家意见正式将该事件诊断为过电压崩溃：一种由无功功率吸收能力耗尽驱动的电压不稳定现象，其中REE自身的预防性操作充当了级联效应的主要向量。

批评的核心是定量的：ICAI的模拟估计，合环操作将卡莫纳节点的崩溃裕度从2964 MW压缩至1268 MW——减少了57%。<KeyFact id="mallado-ferranti" mode="callback">合环物理机制与费兰梯效应 — 第3章，§阶段0</KeyFact>

![根据ICAI专家分析的卡莫纳400 kV节点Q-V曲线](/figuras/fluctuaciones_tension_previas.png)

_图E2 — 卡莫纳400 kV节点电压稳定性Q-V曲线（ICAI专家分析）。该图量化了合环操作导致的崩溃裕度收缩：从2964 MW降至1268 MW，减少了57%，专家意见将其定性为使崩溃在数学上不可避免的条件。来源：IIT-ICAI / Compass Lexecon。_

ICAI数据（2.4 GVAr）与NREL独立分析数据（1.05 GVAr）之间的差异并未改变共同的结论：在这两种情况下，容性注入都超过了系统残余吸收能力，后者估计仅为3.3 GVAr，而通常为5.8 GVAr。

关于级联跳闸，发电行业驳斥了“不当跳闸”的定性，指出运营商的可观测性限制。**Tap-Lag**现象将过电压放大至REE的SCADA不可见的220 kV网络。<KeyFact id="fase-2-taplag" mode="callback">Tap-Lag的完整物理机制 — 第3章，§阶段2</KeyFact>格拉纳达基础设施的所有者确认其保护装置“设置正确且运行正常”，以应对其连接点实际经历的电压。<KeyFact id="granada-disparo" mode="callback">格拉纳达根跳闸 — 第3章</KeyFact>

正是这个盲点使得REE和发电行业的叙事在技术上不可调和：没有对底层网络的可观测性，运营商无法纠正其看不见的东西，而发电厂也无法不对其看到的东西进行跳闸。因此，分歧不在于事实本身——而在于面对双方都承认的工具性限制时的责任归属。

![12:32:56.993 CEST格拉纳达根跳闸的波形记录](/figuras/aluvion_alertas_sobretension_sur.png)

_图E3 — 格拉纳达根跳闸的波形记录（欧洲中部夏令时间12:32:56.993）。波形显示A相集电母线二次侧电压约为145 kV（>1.10 p.u.），该阈值正确触发了过电压保护，但由于Tap-Lag效应，对REE的SCADA不可见，造成了运行盲点，使得预防性干预成为不可能。来源：IIT-ICAI / AELEC。_

第二条论证线索指向监管框架：改革前的P.O. 7.4要求IBR以固定功率因数运行，尽管其电力电子设备具备动态吸收或注入无功的能力，但该规定阻止了这种能力。这一限制将82%的瞬时发电量排除在主动电压控制之外，将责任集中在稀缺的可用同步火电机组上。

根据专家意见，由此产生的定量失衡在数学上是无法解决的：在振荡和合环的震中南部地区，REE仅有0.2 GVAr的感性无功吸收能力，而由其自身操作引起的估计容性注入超过0.7 GVAr。

![根据IIT-ICAI，欧洲中部夏令时间12:30南部地区无功功率平衡](/figuras/asimetria_balance_reactiva_sur.png)

_图E4 — 欧洲中部夏令时间12:30南部地区无功功率平衡。该图记录了-0.6 GVAr的净赤字：仅有0.2 GVAr的感性吸收能力，而合环操作引起的容性注入超过0.7 GVAr，ICAI专家意见将此条件定性为数学上无法解决。来源：IIT-ICAI / Compass Lexecon。_

专家意见的结论确定了三个直接归因于运营商和监管机构的因素：使Q-V裕度饱和的合环操作、因Tap-Lag导致的220 kV网络结构性不可观测性，以及阻止82%的发电机组参与动态电压控制的监管框架（P.O. 7.4）。

## 欧洲视角（ENTSO-E）：NC RfG不足与同步系统分离

ENTSO-E的专家小组提供了三者中最具结构性的视角。其核心论点驳斥了大停电本身是由可再生能源渗透引起的：崩溃并非可再生能源发电过剩或一次惯量不足的结果，而是电压曲线控制框架局限性的结果。该事件揭示了可再生能源资产快速部署与支配其动态行为的电网规范部分过时之间的不对称性。

分析识别出一个基本的技术张力：大多数脱网的设施都具备执行稳健电压控制所需的电力电子设备，但当时有效的西班牙法规禁止或未要求它们提供这种动态服务，迫使它们根据第413/2014号皇家法令以静态功率因数运行。这种监管限制使系统失去了本可以抑制空载线路容性注入的分布式无功支持。

作为直接回应，ENTSO-E在其第二阶段报告中巩固了NC RfG 2.0的更新，该更新计划强制要求所有≥1 MW的非同步模块采用构网型模式：

这种分离防止了容性崩溃和频率骤降——RoCoF超过1.5 Hz/s——波及法国系统和欧洲大陆其他地区。

ENTSO-E的最后警告是结构性的：基于静态潮流和N-1准则的协调安全评估（CSA）和通用电网模型（CGM），在崩溃前瞬间将系统评估为“正常”。对ENTSO-E而言，这表明为传统同步机设计的欧洲大陆运行安全评估标准，在结构上不足以防止高电力电子渗透率系统中的崩溃。

## 解释性综合：三个治理断裂

比较性审查使我们能够超越各方之间的争议，形成二阶诊断：4月28日大停电既不是不可预测的“黑天鹅”，也不是特定技术的失败，而是伊比利亚电力系统中同时存在的三个治理断裂的汇聚表现。

### 运行断裂：因果关系与责任

合环作为触发因素（ICAI）的论点和集体违规作为原因（REE/政府）的论点在技术层面上并非相互排斥：这两个因素都导致了压缩Q-V裕度的容性饱和。然而，它们在法律和经济上的含义是相互排斥的。这种因果模糊性是在没有足够动态仪表化的网络上运行的可预见结果：当系统在所有关键节点没有PMU，也没有实时电压稳定性计算工具时，事后重建不可避免地受到解释的影响。各方之间的默契共识——没有一份报告明确陈述——是监测架构既不足以实时管理事件，也不足以在事后明确解决它。

### 监管断裂：21世纪网络上的20世纪法规

ENTSO-E的立场表明，运营商和发电厂都在旨在治理的系统不适当的法规范围内行事。P.O. 7.4和第413/2014号皇家法令设计了一种针对由响应缓慢的同步质量主导的网络的电压控制方案；将其应用于IBR渗透率为82%的网络，在控制工程术语中，相当于试图用为分钟级动态设计的调节器来稳定一个毫秒级响应的系统。这种不适当性并非未知：P.O. 7.4的更新提案多年来一直处于监管审批过程中。政府报告本身承认，其生效本应是本可以避免崩溃的最相关变化。从这个意义上说，4月28日大停电是监管延迟的可衡量成本。

### 系统性断裂：动态网络上的静态安全工具

关于静态N-1准则不足的共识一致指向一个超越伊比利亚案例的脆弱性。将系统评估为“正常”的潮流模型在数学上无法表示低惯量网络中的容性不稳定现象：它们不求解微分方程，不模拟逆变器控制回路的动态，也不实时计算Q-V裕度。崩溃的进展速度——从首次跳闸到电压归零不到90秒——将现象置于任何人为干预的时间范围之外：当运营商意识到暂态的严重性时，系统已经无法恢复。唯一可行的回应是通过实时动态安全分析进行结构性预防，其在欧洲区域协调中心的部署是ENTSO-E确定的最紧迫改革之一。

### 集中式范式的局限

在三个断裂之下，存在一个报告以零散方式处理的更深层张力：集中式运行范式——一个运营商，可见性限于400 kV水平，通过离散开关电抗器管理电压，并通过小时级市场信号调度同步发电——是为同步质量提供自然阻尼、发电机在几秒内响应的网络设计的。在一个82%的发电由在毫秒内响应、通过PLL自提供同步参考、且其动态行为对400 kV SCADA不透明的逆变器组成的网络中，该范式已达到其管理能力的极限。

4月28日不仅仅是一个大停电案例研究：它是一个标志着在高电力电子渗透率系统中集中式调度模型枯竭的事件，也是21世纪欧洲电网新的分布式实时控制架构的强制性起点。
