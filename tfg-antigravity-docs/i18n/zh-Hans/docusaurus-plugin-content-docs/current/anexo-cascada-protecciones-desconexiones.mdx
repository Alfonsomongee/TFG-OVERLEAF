  <AnnexKeyQuestion>
    从西南地区的根源跳闸到伊比利亚系统的全面崩溃，解列级联是如何传播的？在每个阶段有哪些保护动作？

  <AnnexThesisBox>
    4月28日的级联故障在不到五分钟内经历了四个阶段：(1) 过电压通过西南部400千伏网络传播，因费兰梯效应和调压变压器抽头滞后而放大；(2) 逆变器型电源的ANSI 59保护大规模跳闸，在11秒内损失约4.5吉瓦；(3) 自动防御机制——低频减载和抽水蓄能解列——启动，但面对扰动速度显得不足；(4) 频率崩溃和半岛同步性完全丧失。保护装置按规范动作；但规范本身并未考虑低惯量下普遍过电压的场景。
  </AnnexThesisBox>

  <AnnexBlackoutRelevance>
