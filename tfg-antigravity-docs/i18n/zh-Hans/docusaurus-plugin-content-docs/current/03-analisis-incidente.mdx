<GlitchTitle>事故分析</GlitchTitle>

4月28日的电压归零并非瞬间事件：它是电网静态和动态稳定性逐步且可测量的退化过程的顶点。对崩溃四个阶段（从早晨的振荡到12:33:29 CEST半岛最终隔离）的法医重建，使我们能够精确识别出任何传统保护自动化装置都无法阻止的物理机制。**这里充分体现了能源三难困境的技术顶点：一个由逆变器主导、缺乏传统惯性的系统的物理脆弱性。**

## 阶段0：电网削弱与网格化操作 {#fase-0}

<span id="t1"></span>
4月28日上午，系统在极其薄弱的拓扑结构上运行。在负荷低谷期，南部地区35.8%的400 kV电网和中部地区34.3%的400 kV电网处于断开状态，形成了高转移阻抗的场景。在此电网基础上，系统动力学以两种不同模式的机电振荡形式表现出来：

- 12:03 CEST — 0.6 Hz强迫振荡，振幅70 mHz，耗时4分42秒才衰减。
- 12:19 CEST — 东-中-西0.2 Hz区域间模式：伊比利亚半岛开始与欧洲大陆反相振荡，拉紧比利牛斯联络线。

在这两个暂态过程中，阻尼比骤降至接近1%的值，远低于技术文献（Kundur, 1994）要求的5%最低阈值。这种行为并非前所未有：4月16日、22日和24日的类似事件被当作孤立事件处理，而非系统性退化的症状。

![努涅斯·德·巴尔博亚的振荡和过电压](/figuras/nunez_balboa_precursores.png) _图C1. 努涅斯·德·巴尔博亚 / 前兆：在前期事件期间，努涅斯·德·巴尔博亚400 kV的振荡和过电压。连续的峰值证明了无功功率控制裕度的逐步缩小。来源：IIT-ICAI。_

<KeyFact id="mallado-ferranti">

为了抑制这些振荡，REE执行了一次网格化操作：在12:03至12:30 CEST之间，重新连接了11条因低负荷而断开的400 kV线路。该操作实现了其直接目标——降低阻抗并阻止振荡的冲击——但根据IIT-ICAI报告，引入了一个重要的副作用：由于费兰梯效应，空载重新连接的线路突然向已经缺乏吸收裕度的电网注入容性无功功率。这种注入的量化是技术争议的核心之一：ICAI报告估计高达2.4 GVAr；NREL的独立分析采用了更保守的1,050 MVAr估计。两个数字都一致指出，注入量超过了系统当时的剩余吸收能力，估计仅为3.3 GVAr，而通常为5.8 GVAr（参见[附录九 · 方法论与模型](./anexo-metodologia-modelos-datos-vivos)，专门讨论方法论、模型和模拟器）。

</KeyFact>

IIT-ICAI的专家模拟估计，在网格化之后，卡莫纳400 kV节点到崩溃点的距离从2,964 MW的裕度缩小到1,268 MW——减少了57%，使系统接近容性饱和阈值。

## 阶段1：阻尼丧失与根故障（12:32:57 CEST） {#fase-1}

第一个暂态——12:03 CEST的0.6 Hz振荡——的性质是直接技术争议的对象。REE将其归类为源于巴达霍斯某光伏电站控制回路的强迫振荡。而ICAI报告则认为，这是一种由1%的系统阻尼比加剧的自然区域间模式，其根源与安达卢西亚地区停运的联合循环电厂缺乏电力系统稳定器（PSS）有关。

<FrequencyChart isGallery={true} />

_图C4. 崩溃末期频率演变。数据：ENTSO-E / REE。自行编制的交互式可视化。_

频率的演变不应被解释为大停电的主要原因，而是已经在电压和无功功率层面发展的不稳定性的最终表现。当级联断开已经摧毁了大部分可用发电时，频率下降才出现。因此，频率在时间上排列了事件的最后阶段，但并未穷尽其因果机制：物理根源在于容性饱和、Q-V裕度缩小以及无功吸收能力的逐步丧失。

不稳定性在12:19 CEST随着0.2 Hz模式的出现而加剧，欧洲相量测量遥测确认这是同步区域的东-中-西自然模式：减少的伊比利亚旋转质量与欧洲惯性中心反相振荡，实现了第2章描述的鞭梢效应。

<span id="t5"></span>
<KeyFact id="granada-disparo">

不可逆点于12:32:57 CEST达到。格拉纳达省一个汇集变电站的400/220 kV变压器因其过电压保护动作而断开，检测到220 kV侧电压值约为*244 kV*，超过了介电安全阈值。影响的严重程度不在于损失的355 MW有功功率——这对系统来说是可控的数字——而在于瞬时且不可恢复地损失了165 MVAr的感性无功功率吸收能力。在一个容性无功饱和且Q-V裕度缩小的系统中，这个吸收点的消失导致周围节点电压阶跃上升：连锁反应的物理触发点（参见[附录三 · 保护与断开](./anexo-cascada-protecciones-desconexiones)）。

</KeyFact>

## 阶段2：分接头滞后现象与电压解耦（12:32:57–12:33:18 CEST） {#fase-2-taplag}

根故障后的21秒是法医辩论的技术核心。

<span id="t4"></span>
在格拉纳达断开后，输电网电压的上升趋势揭示了400 kV基础设施与底层汇集网络行为之间的分歧：分接头滞后现象。

在阶段1期间，由频率振荡引起的电压波动和下降导致400/220 kV和400/132 kV变压器通过其OLTC上调分接头以提高二次侧电压。当过电压在400 kV电网中爆发时，这些变压器被困在自己的机械惯性中：OLTC的电机和齿轮机构被有意通过时间延迟减慢，以避免在短暂扰动下发生机械振荡。面对超快速的电气暂态，分接开关变得过于缓慢，无法及时降低变比。

分接头滞后解耦和过电压传播的放大视觉证据保存在附录三中。

<TapLagSequence />

_图C5. 输电网与汇集网络之间的分接头滞后序列和电压解耦。自行编制。_

分接头滞后将部分可观察的过电压转变为不可见的系统性威胁。输电网可能看起来仍在允许范围内，而下游的汇集网络已经超过了与逆变器保持连接不相容的阈值。这种分歧解释了为什么电厂的保护装置可以从其连接点正确动作，同时从运营商的聚合视角看似乎为时过早。这种现象并非局部细节：它是先前网格化与ANSI 59级联跳闸之间的物理桥梁。

这种机械上的无能造成了REE控制室中的“幻象”。运营商的SCADA监测400 kV一次侧，观察到电压偏高但理论上低于法规异常限值435 kV（P.O. 1.1）。然而，在下游的220 kV和132 kV网络中，电压攀升至1.2 p.u.以上——由于底层网络不可观测，这些阈值对国家调度中心不可见。

面对其电力电子设备无法承受的电压，太阳能和风能电站的逆变器触发了其内部过电压保护系统（ANSI 59功能）。这里存在事件中最大的法医分歧之一：REE将这些损失归类为“不当跳闸”，声称其400 kV电网中不存在断开值；ICAI分析则认为，电站在其连接点实际经历的过电压下正确动作，该过电压位于带有OLTC的变压器下游。分接头滞后因此为连锁断开的正反馈回路创造了条件。

## 阶段3：通往电压归零之路（12:33:18—12:33:29 CEST） {#fase-3}

在11秒内，半岛电网通过由潮流方程决定的恶性循环自我毁灭。当IBR电站大规模断开以自我保护时，电网瞬时失去了吸收无功功率的能力。同时，有功功率的下降减少了400 kV线路的潮流，由于费兰梯效应增加了其容性注入，将最受应力节点的电压推至443 kV以上。每次断开都抬高了电压，迫使新的断开发生。

<BlackoutPropagationMap />

_图C7. 阶段3期间IBR级联断开的地理传播。基于ENTSO-E / 分析委员会数据的自行编制交互式模拟。_

<span id="t6"></span>
级联中最严重的打击最初集中在巴达霍斯（12:33:16 CEST，*t=19 s*），紧接着下一秒，在塞哥维亚、塞维利亚和韦尔瓦变电站。在关键的5秒窗口（12:33:19–12:33:24 CEST）内，连锁反应断开了<CuestionAbierta metricKey="potencias_cascada.perdida_generacion_total_cascada">15,000 MW</CuestionAbierta>的发电（超过先前伊比利亚瞬时容量的50%），使<CuestionAbierta metricKey="potencias_cascada.demanda_sin_suministro_espana">25.2 GW</CuestionAbierta>的西班牙负荷完全失去供电，将系统推向任何恢复可能性之外。（关于逐秒详尽时间线和每次断开的功率量，请参见[附录三 · 保护与断开](./anexo-cascada-protecciones-desconexiones)，其中保存了保护、断开和级联传播的详细文档）。

随着级联摧毁剩余发电，频率开始以极端的RoCoF下降（估计二次峰值<CuestionAbierta metricKey="rocof.rocof_pico">1.5 Hz/s</CuestionAbierta>），激活了UFLS方案。在12:33:20 CEST越过49.5 Hz阈值时，超过2,000 MW的抽水蓄能自动断开，当电网降至<CuestionAbierta metricKey="cronologia_cascada.frecuencia_umbral_deslastre">49.0 Hz</CuestionAbierta>以下时，首批工业负荷被切除。

<KeyFact id="paradoja-ufls">

UFLS的动作揭示了所谓的UFLS悖论：为了稳定频率而切断有功负荷，方案同时消除了该负荷的感性无功功率消耗。在一个容性无功饱和的电网中，消除最后的吸收点——电机和工业负荷——导致了过电压的新一轮上升，强化了UFLS本意要阻止的崩溃。为频率缺额设计的防御逻辑在面对主要由电压不稳定性驱动的崩溃时适得其反。

</KeyFact>

在最后时刻，内部发电的巨大缺额导致了比利牛斯潮流的剧烈反转：交流线路达到了约3,800 MW有功功率的暂态进口峰值（ENTSO-E事实报告，第108-109页），来自法国。同时，自12:08 CEST起固定在PMODE1模式的HVDC INELFE-1联络线继续从伊比利亚系统抽取约1 GW的有功功率（按回路和容量的精确细分可在[附录四 · 互联与潮流](./anexo-interconexiones-flujos)中审计）。这种不对称运行急剧压缩了来自欧洲大陆的净支撑能力。
