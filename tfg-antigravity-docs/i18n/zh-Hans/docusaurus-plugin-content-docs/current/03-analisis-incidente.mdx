<GlitchTitle>事件分析</GlitchTitle>

4月28日的零电压并非瞬间事件，而是电网静态和动态稳定性逐步且可测量退化的最终结果。对崩溃四个阶段（从早上的振荡到12:33:29 CEST半岛最终隔离）的法医重建，使我们能够精确识别出任何传统保护自动化装置都无法阻止的物理机制。**能源三难困境的技术顶点在此充分显现：一个由逆变器主导、缺乏传统惯性的系统的物理脆弱性。**

## 阶段0：弱化电网与网格化操作 {#fase-0}

<span id="t1"></span>
4月28日上午，系统在极其薄弱的拓扑结构下运行。在负荷低谷期，南部地区35.8%的400 kV电网和中部地区34.3%的400 kV电网处于断开状态，形成了高转移阻抗的场景。在此电网基础上，系统动力学以两种不同的机电振荡模式表现出来：

- 12:03 CEST — 0.6 Hz强迫振荡，振幅70 mHz，耗时4分42秒才衰减。
- 12:19 CEST — 0.2 Hz东-中-西区域间模式：伊比利亚半岛开始与欧洲大陆反相振荡，拉紧了比利牛斯山脉联络线。

在这两个暂态过程中，阻尼比骤降至接近1%，远低于技术文献（Kundur, 1994）要求的5%最低阈值。这种行为并非前所未有：4月16日、22日和24日的类似事件被当作孤立事件处理，而非系统性退化的征兆。

![努涅斯·德·巴尔博亚的振荡与过电压](/figuras/nunez_balboa_precursores.png) _图10. 前兆事件期间努涅斯·德·巴尔博亚400 kV的振荡与过电压。连续的峰值证明了无功功率控制裕度的逐步收紧。来源：IIT-ICAI。_

<KeyFact id="mallado-ferranti">

为了抑制这些振荡，REE执行了一次网格化操作：在12:03至12:30 CEST之间，重新连接了因低负荷而保持断开的11条400 kV线路。该操作实现了其直接目标——降低阻抗并阻止振荡的冲击——但根据IIT-ICAI报告，引入了一个重要的副作用：由于费兰梯效应，空载重新连接的线路突然向一个已经缺乏吸收裕度的电网注入容性无功功率。这种注入的量化是技术争议的核心之一：ICAI报告估计高达2.4 GVAr；NREL的独立分析采用了更保守的1,050 MVAr估计值。两个数字都一致指出，注入量超过了系统当时的剩余吸收能力，该能力估计仅为3.3 GVAr，而通常为5.8 GVAr（[*参见交互式费兰梯效应拓扑图*](./anexo-interactivos#topology)）。

</KeyFact>

<span id="t3"></span>
IIT-ICAI的专家模拟估计，在网格化操作后，卡莫纳400 kV节点到崩溃点的距离从2,964 MW的裕度缩小到1,268 MW——减少了57%，使系统接近容性饱和阈值。

![WAMS示波图捕获 (0.6 Hz)](/figuras/wams_oscilaciones_carmona.png) _图11. WAMS示波图捕获——卡莫纳0.6 Hz振荡（12:03 CEST）。WAMS系统能够以毫秒级分辨率观察大陆动力学。来源：ENTSO-E / REE。_

## 阶段1：阻尼丧失与根事件跳闸 (12:32:57 CEST) {#fase-1}

第一个暂态——12:03 CEST的0.6 Hz振荡——的性质是直接技术争议的对象。REE将其归类为源自巴达霍斯某光伏电站控制回路的强迫振荡。而ICAI报告则认为，这是一种由1%的系统阻尼比加剧的自然区域间模式，其根源与安达卢西亚地区处于停机状态的联合循环机组缺乏电力系统稳定器（PSS）有关。

不稳定性在12:19 CEST加剧，出现了0.2 Hz模式，欧洲相量测量数据证实这是同步区域的东-中-西自然模式：伊比利亚半岛减少的旋转质量相对于欧洲惯性中心反相振荡，实现了第2章描述的鞭梢效应。

<span id="t5"></span>
<KeyFact id="granada-disparo">

不可逆转点出现在12:32:57 CEST。格拉纳达省一个汇集变电站的400/220 kV变压器因其过电压保护动作而断开，检测到220 kV侧电压约为*244 kV*，超过了介电安全阈值。影响的严重程度不在于损失的355 MW有功功率——这对系统来说是可控的——而在于瞬间且不可恢复地损失了165 MVAr的感性无功功率吸收能力。在一个容性无功饱和且Q-V裕度降低的系统中，这个吸收点的消失导致周围节点电压出现阶跃上升：这是连锁反应的物理触发点（探索[交互式图表库](./anexo-interactivos)）。

</KeyFact>

## 阶段2：Tap-Lag现象与电压解耦 (12:32:57–12:33:18 CEST) {#fase-2-taplag}

根事件跳闸后的21秒是法医辩论的技术核心。

<span id="t4"></span>
格拉纳达断开后，输电网电压的上升趋势揭示了400 kV基础设施与底层汇集网络行为之间的差异：即Tap-Lag现象。

在阶段1期间，由频率振荡引起的电压波动和下降导致400/220 kV和400/132 kV变压器通过其OLTC上调分接头以提高二次侧电压。当400 kV电网出现过电压时，这些变压器被困在了自身的机械惯性中：OLTC的电机和齿轮机构有意通过时间延迟来减缓，以避免在短暂扰动下发生机械振荡。面对超快速的电气暂态，分接开关变得过于缓慢，无法及时降低变比。

## 阶段3：通往零电压之路 (12:33:18—12:33:29 CEST) {#fase-3}

<StickyCollapse />

在11秒内，半岛电网通过由潮流方程决定的恶性循环自我毁灭。当IBR电站为自我保护而大规模断开时，电网瞬间失去了吸收无功功率的能力。同时，有功功率的下降减少了400 kV线路上的潮流，由于费兰梯效应增加了其容性注入，将最紧张节点的电压推高至443 kV以上。每次断开都推高电压，迫使新的断开发生。

<span id="t6"></span>
级联中最严重的打击最初集中在巴达霍斯（12:33:16 CEST，*t=19 s*），紧接着下一秒，集中在塞哥维亚、塞维利亚和韦尔瓦变电站。在关键的5秒窗口内（12:33:19–12:33:24 CEST），连锁反应断开了<CuestionAbierta metricKey="potencias_cascada.perdida_generacion_total_cascada">15,000 MW</CuestionAbierta>的发电容量（超过先前伊比利亚瞬时容量的50%），使<CuestionAbierta metricKey="potencias_cascada.demanda_sin_suministro_espana">25.2 GW</CuestionAbierta>的西班牙负荷完全失去供电，并将系统推向任何恢复可能性之外。（关于逐秒详尽时间线和每次断开的确切功率量，请参见法医库中的[表16 / 时间线](./anexo-interactivos)）。

随着级联摧毁剩余发电，频率开始以极端的RoCoF下降（估计二次峰值<CuestionAbierta metricKey="rocof.rocof_pico">1.5 Hz/s</CuestionAbierta>），触发了UFLS方案。在12:33:20 CEST越过49.5 Hz阈值时，超过2,000 MW的抽水蓄能自动断开，当电网频率降至<CuestionAbierta metricKey="cronologia_cascada.frecuencia_umbral_deslastre">49.0 Hz</CuestionAbierta>以下时，首批工业负荷被切除。

<KeyFact id="paradoja-ufls">
