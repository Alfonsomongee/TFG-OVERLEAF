2025年4月28日，伊比利亚同步系统发生电压崩溃，数秒内摧毁了超过15 GW的发电容量（导致约25.2 GW的负荷中断），使约5700万人失去电力供应。就其规模和传播速度而言，这一事件在欧洲大陆系统中是二十多年来前所未有的。本文并非对该事件的时间顺序重建：而是对竞相解释该事件的技术、监管和运行叙事进行批判性和比较性分析。

## 目的与范围

此次崩溃——其特征是在逆变器基资源（IBR）高渗透率的背景下，与过电压现象相关的连锁脱网——引发了对其根本原因和责任归属的深刻解释分歧。本研究考察了三种主要的机构观点：

*（注：分析基于四份主要报告——政府、REE、IIT-ICAI/AELEC和ENTSO-E——归纳为三种观点，因为政府和REE的报告共享基本的因果前提。）*

行政当局观点（政府 / REE，系统运营商，控股公司Redeia的子公司）。国家安全委员会分析委员会的报告从合规性的角度解释此次崩溃。其论点将事件的恶化归因于感性无功功率吸收不足，未能抑制电压上升，违反了运行程序P.O. 7.4的要求。

发电部门观点（ICAI / AELEC报告）。IIT-ICAI和Compass Lexecon的专家分析将责任转移到REE的具体运行决策上。核心论点质疑运营商执行的网格化（*meshing*）操作，认为其在低同步强度场景下增加了电网的容性贡献，并产生了因220 kV电网可观测性限制而放大的过电压脉冲——这一现象被称为抽头滞后（Tap-Lag）。

欧洲管理者观点（ENTSO-E）。ENTSO-E的事实报告采用大陆同步区域的视角：分析了区域间振荡的传播，并质疑了N−1准则在面对以电力电子为主导的系统中超快动态现象时的充分性。

![崩溃序列复现](/figuras/albustami_ieee39_secuencia.png) _图1. 崩溃序列复现（OA/AA交互）。来源：Albustami等人，2025年。_

本研究的范围围绕将这三种叙事与欧洲网络规范——特别是RfG法规——以及现代逆变器主导系统中的电压稳定性原理进行对比，旨在识别影响欧洲电力系统在脱碳转型中韧性的结构性教训、方法论局限性和监管空白。叙事分析基于对暂态过程的电磁重建，该重建建立在PMU和WAMS记录之上，并与四个机构公布的示波图证据一致。

## 伊比利亚系统的结构性脆弱性

能源转型深刻改变了半岛系统的动态。同步发电机被IBR加速替代，减少了与电网耦合的旋转质量，并同时降低了两个关键参数：系统惯量（*H*）——在半岛南部降至1.3秒至1.8秒的区域值，低于技术文献中与动态裕度受损相关的2秒阈值——以及节点处的可用短路功率。这种双重缩减不仅影响有功功率-频率轴：它还严重削弱了系统在快速暂态过程中动态吸收无功功率和维持电压的能力，而这正是崩溃发生的核心轴线。

![电力系统的机电形态演变](/figuras/futured_grid_evolution.png) _图2. 电力系统的机电形态演变（IBR替代）。大型旋转质量的替代急剧降低了系统总惯量。来源：FutuRed，2024年。_

事件发生当天上午，系统在需求低谷条件下以高比例非同步可再生能源发电运行（其详细结构在技术背景部分描述）。为平衡发电，REE解列了几乎所有可用的火电机组，使同步发电机数量降至历史最低水平。IBR机组几乎全部以电网跟随模式运行：这些逆变器需要稳定的外部电压和频率作为同步参考。随着同步机组的消失，系统失去了其动态吸收无功功率的主要机制，从而也失去了对电压暂态的自然阻尼。

除了这种内部脆弱性之外，伊比利亚半岛的结构性孤立也加剧了问题。其跨境互联容量仅为峰值负荷的7.9%——远低于欧盟目标——使得伊比利亚系统在紧急情况下无法从欧洲大陆核心区域导入动态稳定性。低同步强度与相对电网孤立的结合，构成了使得在12:33:29.741 CEST无法阻止过电压连锁反应的脆弱性。

:::note 地理范围
此次崩溃同时影响了西班牙和葡萄牙。REN（葡萄牙国家电网）的系统通过高压互联与REE电气同步；当西班牙半岛系统电压降至零时，葡萄牙电网在毫秒内崩溃。葡萄牙未供电负荷达到约5.8 GW，葡萄牙系统完全恢复需要约12小时（而西班牙系统约为15.5小时）。第4章和第7c章详细分析了葡萄牙方面的情况。在本文中，“伊比利亚系统”指代ES+PT联合同步区域，而“半岛系统”仅在分析局限于西班牙电网时使用。
:::

## 方法论：法医三角测量与交叉验证

本研究采用比较法医分析方法，分为三个阶段：

1.  **主要来源汇编**。系统研究官方专家报告，这些报告基于对系统运营商超过170 GB技术记录的处理，包括SCADA遥测和示波图记录。

2.  **叙事三角测量**。围绕两个主要分歧点——网格化操作的管理和220 kV电网的不可观测性——系统对比行政当局的论点与发电部门的专家分析。

3.  **技术交叉验证**。将时间序列与NREL关于区域间振荡的独立分析进行比对，该分析基于覆盖大陆的相量测量单元（PMU）记录——这些数据的机构独立性使其能够仲裁不同版本。

![欧洲同步系统中PMU的拓扑位置](/figuras/pmu_sensors_europe.png) _图3. 欧洲同步系统中PMU的拓扑位置。覆盖密度对于独立验证区域间振荡至关重要。来源：NREL。_

鉴于事件后产生的大量技术文档，大型语言模型已被用作文档辅助工具——分类、综合和关键数据提取。其应用严格限于文档组织：对于抽头滞后机制或UFLS悖论等快速动态现象，它们存在已知局限性。技术比较、因果关系评估以及本文的结论完全由作者的判断负责。
