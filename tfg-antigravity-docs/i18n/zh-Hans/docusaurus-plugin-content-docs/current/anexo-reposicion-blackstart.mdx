  <AnnexThesisBox>
    4月28日伊比利亚半岛的恢复过程结合了两种并行且协调的策略：本地水电站和火电站的黑启动以构建孤立子系统（恢复孤岛），以及从法国互联电网引入参考电压以重新为北部输电干线供电。尽管联合循环机组并网初期存在延迟，但利用欧洲大陆参考电压和抽水控制甩负荷，使得在不到10小时内恢复了90%的供电，证明了协调应急计划的有效性。
  </AnnexThesisBox>
