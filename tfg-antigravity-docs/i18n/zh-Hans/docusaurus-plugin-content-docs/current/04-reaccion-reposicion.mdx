## 应急管理：从P.O. 1.1到P.O. 1.6

P.O. 1.1规定了稳态运行标准，基于满足N-1准则以及维持输电网电压在380 kV至435 kV之间。4月28日的级联事件显示了这些标准在低惯量网络中针对超快速动态暂态的静态验证局限性：安全极限在11秒窗口内被超越，包括UFLS在内的自动防御方案适得其反。REE在停电状态（OB3标准）下接管了手动控制。

机构反应是立即且同时在多个方面进行的：

- 12:34 CEST — REE与REN确认整个葡萄牙电网同样无电压。
- 12:36 CEST — 通过EAS正式通知其他欧洲运营商，将伊比利亚区块的运行状态修改为“恢复”。
- 12:44 CEST — REE和OMIE暂停所有日内市场和平衡服务市场，授予完全权限，仅根据技术可行性标准进行调度。

恢复策略规定在逐步重新通电过程中，将伊比利亚半岛有控制地分割为七个独立运行区域——南部区、塔霍-中部区、莱万特区等。

## 黑启动策略：水电站和联合循环电厂

由于几乎全部发电机组由电网跟随型IBR组成——技术上无法在没有稳定外部电网的情况下产生电压波形——系统的生存和重启完全依赖于具有自主启动能力的同步电机。

水电站（径流式和抽水蓄能式）是首批被调度以对隔离段通电并创建首批电气孤岛的电站。然而，这些微系统的运行揭示了在最小惯量下运行的困难：空载线路通电引起了显著的电容暂态，导致多次启动尝试失败。

![水电站黑启动的时间部署和有效性](/figuras/black_start_hidroelectrico.png)
_图D2 — 水电站黑启动的时间部署。该图区分了成功和失败的通电尝试，表明初始恢复依赖于能够在低短路功率电气孤岛中形成电压的同步电机。来源：ENTSO-E / REE。_

失败是显著的：坎塔布里亚和莱万特孤岛未能维持并不得不重新启动；分配给马德里的电站在多次连续尝试后未能稳定其参数；安达卢西亚的自主启动未成功，迫使优先考虑来自摩洛哥的外部支援作为南部地区的电压参考。

空载线路通电暂态在400 kV自耦变压器中产生了高达额定电流10倍的磁化涌流，导致新形成的脆弱孤岛电压下降10-20%。更成问题的是“和应涌流”现象：新变压器的通电使已运行的并联变压器的磁通饱和，产生严重的谐波畸变，衰减时间超过10秒，导致多个孤岛在稳定之前崩溃。在至少三个有记录的情况下，变压器差动继电器将这些暂态解释为内部短路并下令跳闸，迫使孤岛过程从头开始。

一旦水电站孤岛能够最小限度地稳定其参数，策略转向通过天然气联合循环电厂（CCGT）和核电站辅助服务来巩固其机电稳定性。这些机组并非为了满足商业负荷而连接，而是为了构建系统的“电磁骨架”：它们提供了在授权大规模负荷重新接入之前必不可少的短路功率（$S_{sc}$）、惯量（$H$）和动态无功功率管理能力。

葡萄牙系统执行了类似的方案，依靠HPP 1-Centro水电站和CCGT 1-Norte联合循环电厂。在20:22 CEST，通过同步检查继电器验证，葡萄牙孤岛与已耦合到欧洲大陆频率的西班牙区域同步，保证了伊比利亚半岛全面恢复的可行性。

## 国际协调：RCC、Swissgrid和大陆重新同步

区域协调中心（RCC）的工具——特别是负责欧洲西南部的Coreso——通过稳态静态潮流评估安全性，无法预测与低惯量相关的电压不稳定或超快速动态现象。因此，其所有崩溃前的分析均显示“OK”状态，伊比利亚区块在停电发生前一刻在EAS中仍标记为“正常”。

一旦电压归零，欧洲指挥层级通过由Swissgrid和Amprion运营的同步区域监视器（SAM）激活。在12:49至12:54 CEST之间建立了统一指挥结构：

- REE → 断开的伊比利亚孤岛的频率领导者
- *Swissgrid* → 稳定欧洲大陆其余部分
- RTE（法国） → 总体重新同步领导者

在此方案下，RTE在其内部平衡机制中激活了高达4,500 MW的报价以支持对西班牙的出口，从而实现了半岛北部和东部400 kV走廊的通电。

## 电源结构演变和最终稳定

尽管太阳能和风电场在物理上完好无损且具有可用的一次能源，但其重新接入在初始关键阶段受到限制。电网跟随模式逆变器需要预先读取一个强大的外部电网，才能通过其PLL环路注入电流：没有这个参考，它们无法运行。重新通电的全部责任落在了CCGT、剩余燃煤电厂和核电站的顺序耦合上。

![伊比利亚半岛重新通电期间技术电源结构的演变](/figuras/evolucion_mix_reenergizacion.png)
_图D5 — 重新通电期间技术电源结构的演变。该序列表明，恢复最初并不依赖于可用的IBR，而是依赖于能够提供电压参考、惯量和短路功率的同步发电——水电、联合循环、剩余燃煤和核电——的逐步连接。来源：ENTSO-E / REE。_

负荷以精心计算的离散块重新连接：

- 13:07 CEST — 从Irún变电站首次供电31 MW。
- 23:32 CEST — 21台火电机组同步，覆盖负荷达到13,039 MW（约55%预期负荷）。
- 00:06 CEST（4月29日） — REE重新激活自动频率恢复备用（aFRR）主控制器，使系统恢复其自动二次调频能力。
- 01:38 CEST（4月29日） — 首批指令重新接入风电场和热电联产电厂。
- 07:05 CEST（4月29日） — 解除对全部RCR制度的限制。REE确认99.95%的国家供电恢复。

### 电网已修复，经济暂停

在4月29日07:05，REE解除了最后运行限制。99.95%的伊比利亚半岛供电点有电压。下图以五分钟分辨率记录了这一过程：4月28日上午的正常负荷曲线，12:33 CEST的骤降，停电的平坦线，以及直到4月29日凌晨正常化的阶梯式恢复斜坡。

电网已修复并不意味着经济也已修复。服务业和家庭在数小时内恢复了正常消费。高耗电工业——电弧炉、水泥厂、炼油厂——需要整整一周。其连续过程不允许立即重新启动：在恢复到额定状态之前，需要进行质量测试、设备重新校准和安全协议。下图记录了截至5月5日的这一部门差距。
