## 1. “过电压驱动型大停电”范式

初步分析表明，这是一次由惯性不足或频率偏差导致的典型崩溃。然而，由科米利亚斯宗座大学技术研究所（IIT）进行的独立研究——经同行评审并在《ScienceDirect》上发表（Rouco, Lobato, Echavarren, 2026）——引入了一个前所未有的技术概念：过电压驱动型大停电。

:::warning [技术披露]
致命序列并非普遍性的电压下降。当保护逻辑被激活时，电网遭受了由大规模过电压触发的级联跳闸。负荷的断开以及400 kV线路（未连接足够的电抗器）注入的巨大容性无功功率，将电压推高至发电保护装置的极限以上。12:32:57在格拉纳达发生的400/220 kV变压器跳闸（损失355 MW）是级联反应的导火索。
:::

根据取证重建，以固定功率因数模式运行的并网型逆变器连接的电厂，对有功功率振荡的反应是注入巨大的无功功率斜坡。面对一个弱化的电网（短路比低），这些逆变器的锁相环（PLL）导致了系统无法阻尼的不稳定性。

## 2. 运行不透明性与高压直流输电（HVDC）的作用

调查中最具争议的一点是系统运营商（REE）的行为。2025年7月，独立联合体（AELEC、INESC TEC、Compass Lexecon）指责其在状态估计器和相量测量单元（PMU）数据方面严重缺乏透明度。

HVDC INELFE-1模式切换至PMODE1及其对动态支撑能力的关键影响，在第[2](./02-contexto.mdx)章和第[3](./03-analisis-incidente.mdx)章中有详细分析。

## 3. 制度后果与巨额诉讼

大停电不仅破坏了电力系统，也破坏了行业的制度关系，引发了史无前例的司法浪潮：

- **国家市场与竞争委员会（CNMC）案卷：** 自2025年4月以来，已启动66项制裁程序。REE和阿尔马拉斯核电站的所有者面临“非常严重”的指控（最高6000万欧元）。与此同时，11家发电商（包括Endesa、Iberdrola和Mercuria Solar）因违反电网规范面临“严重”指控。
- **大规模民事诉讼：** 随着2026年4月诉讼时效到期，Repsol等工业巨头已正式对系统提起诉讼，索赔1.25亿欧元，涉及利润损失和对石化联合体的损害。Iryo和Moeve也已通知其起诉意向。
- **解密录音：** 参议院调查委员会的听证会公开了REE控制室的录音。录音中，操作员将12:00的严重振荡归咎于光伏电站操作员的“管理不善”。然而，CNMC澄清说，0.6 Hz的振荡是由巴达霍斯一座大型光伏电站的控制回路缺陷引起的，而非人为“管理不善”。这表明，尽管控制室的初步诊断是错误的，但在最终崩溃前几分钟风险已迫在眉睫。

### Iberdrola诉Redeia案

2026年4月21日，马德里第15商事法院（法官Teodoro Ladrón）驳回了REE和Redeia提出的管辖权异议，确认民事法院有权审理Iberdrola提出的不正当竞争诉讼。该裁定明确，该程序不会评判大停电的技术原因——这属于CNMC的专属权限——而是评判Redeia管理层的公司行为和公开声明，Iberdrola认为这些行为和声明损害了其声誉和股票市值。

## 4. 监管回应：构网型（Grid-Forming）强制令

### 伊比利亚储能热潮

大停电后，为维持以天然气加强的系统，十个月内产生了高达6.66亿欧元的额外系统成本。作为直接反应，西班牙电池市场经历了前所未有的加速：已安装的电池储能系统（BESS）容量增长了589%，从象征性的28 MW增加到约193 MW（运行中），在一年内推动了用于黑启动服务的原生电网架构。

## 危机结论

回顾来看，到2026年，“2025年大停电”已不再被视为由水力干旱或太阳能过剩引发的偶然事故。它是首个有文献记载的、因现行监管-技术框架与高可再生能源渗透率系统物理特性结构性不匹配而导致的崩溃实例。伊比利亚半岛被迫成为了一个活生生的实验室，迫使欧洲为未来十年重写电力稳定性的规则。
