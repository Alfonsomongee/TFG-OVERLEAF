本学位论文的撰写是在一个非典型的方法论背景下进行的：在2024-2026两年期间，伊比利亚电力系统同时面临系统性危机，而自然语言处理工具也正经历加速变革。能够快速处理数百页技术文档的大型语言模型（LLM）的可用性，恰逢一年内发布了四份主要专家报告和十份关于同一事件的学术分析。本章将透明地记录这些工具是如何被整合的，它们具体执行了哪些任务，检测并纠正了哪些系统性错误，以及由此对工程研究实践产生的认识论反思。

## 方法论应用：五项操作功能

原始文献主体包括技术档案、ENTSO-E法规、超过200页的官方报告、IIT-ICAI的PSS/E仿真、CNMC会议纪要、NREL的波形记录以及大量专业新闻资料。在没有计算机辅助的情况下进行线性阅读，与学位论文的学术期限不相容。生成式模型的整合围绕五个明确界定的操作功能展开，其中任何一个都不涉及对系统物理的自主因果推理：

工作流程分为三个连续阶段，并带有一个修正循环：

```text
[原始来源] ──> [LLM辅助] ──> [物理验证过滤器] ──> [论文正文]
                             ▲                              │
                             └──────────────────────────────┘
                               (检测到幻觉时重新制定提示)
```

方法论上决定性的因素不是LLM辅助本身，而是介于模型任何输出与将其纳入文本之间的物理验证过滤器：基尔霍夫定律、Q-V曲线、转子摆动方程以及与原始来源的核对。当过滤器检测到与系统力学不相容的推理时，提示会以额外的语义约束重新制定，并重新开始循环。

## 验证与核实：五个错误推理案例

在像电力系统动力学这样因果关系密集的领域中使用生成式模型，系统地揭示了一种电力系统无法容忍的行为：统计类比推理。LLM倾向于将“典型”的因果模式——其训练语料库文献中最常见的模式——应用于物理结构非典型的案例。4月28日事件，由于其双重性质（电压稳定而非频率平衡），相对于20世纪技术文献中记录的大多数停电事件而言，是一个非典型案例，这使得观察AI“默认”偏离真实现象的点特别富有成效。

### UFLS悖论案例

最说明错误模式的案例：当被问及减载在事件发展中的作用时，模型系统性地提供了从经典停电中继承的解释，其中UFLS构成了最后一道防线，并且通常通过恢复频率-有功功率平衡来成功保留部分网络。这种推理对于模型训练所依据的事件集合在物理上是正确的，但对于4月28日事件无效：在由Q-V平面主导的崩溃中，UFLS的激活同时移除了被断开负载提供的感性无功功率吸收点，从而加剧了过电压，而非缓解它。

修正需要制定一个带有明确分析平面限制的提示，并手动验证由此产生的推理是否与NREL在12:33:19–12:33:27 CEST时间段内发布的波形图一致。相图模拟器记录在[附录九 · 方法论与模型](./anexo-metodologia-modelos-datos-vivos.mdx)中。

### 分接头滞后案例

模型对OLTC的定性描述在稳态下是正确的，但默认假设了实际机电组件不具备的比例和瞬时响应。为避免追逐而有意引入的延迟，在4月28日转化为相对于电气暂态过程滞后的变比，从而将过电压倍增到220 kV和132 kV网络——这是操作员SCADA系统无法察觉的现象，因为其锚定在400 kV一次侧测量值上。整个分接头滞后的因果链需要事先向模型描述OLTC的时间常数，并禁止其假设准瞬时响应。

### 电网容性贡献案例

估计注入的1,050 MVAr容性无功必须对应于在空载状态下运行的400 kV线路的横向导纳（$Y_t$）效应（费兰梯效应）。验证包括在线路π模型上重现无功平衡，将数量级与波形图和IIT-ICAI报告的诊断进行对比。

### 0.6 Hz振荡案例

这说明了在存在机构分歧的法医背景下使用AI的一个特定局限性。当专家严谨性要求保留分歧时，模型倾向于产生一个整合响应——对来源进行平均后的“最可能”解读。该模式的起源正是论文需要呈现为未解决分歧的数据，而非编辑共识。

### 网络拓扑案例（因数据缺失导致的幻觉）

这个案例揭示了一个根本性的脆弱性：LLM旨在完成模式。由于特定逆变器控制回路和变电站拓扑的确切细节因关键安全原因不属公共领域，模型通过生成“典型”但虚构的网络架构来填补信息空白，从而陷入结构性幻觉。AI无法从互联网上的通用数据推断出封闭关键基础设施的现实。

这五个案例允许提出的总体观察：自动辅助在处理任务——提取、综合、结构化、制表、辅助写作——中效用最大，而在因果推理任务中效用最小，甚至适得其反，特别是对于训练语料库中代表性不足的物理现象。

## 批判性反思：工程研究中的AI

所记录的经验导致了一个结构性的结论，既非胜利主义也非灾难主义：生成式模型是研究者认知过程的强大加速器，但它们基于概率逻辑运作，这与支配物质系统物理的决定性逻辑不一致。

### 方法论含义

使用AI并不能免除研究者掌握其研究对象的技术内容；相反，它对此提出了更严格的要求。只有具备足够技术能力识别物理上不可能的推理的研究者，才能安全地使用能够以流畅修辞产生这种推理的模型。输出语言上的似真性与其物质正确性之间的不对称，构成了在要求严格的技术领域使用这些工具的主要风险，并且只能通过工具无法提供的内容掌握来抵消。

### 伦理-学术含义

在本工作中，自动辅助被用作处理工具，而非推理的替代品。所有内容决策——问题框架、来源层级、关于4月28日崩溃的因果论点的表述、对机构叙述的比较评估、最终结论——完全是作者的责任。AI不会签署学位论文，也不会坐在答辩委员会面前：工程师以其名义为所陈述事实的物质因果性背书，这种背书是不可转让的。

### 前瞻性学科含义

未来十年的电力系统——由电力电子主导，具有亚周期尺度的相关动态，以及常规操作员无法实时捕获的电压-无功相互作用——将需要结合算法模型处理速度与PSS/E类模拟器物理鲁棒性的决策支持工具。整合并非易事：模拟器求解方程；LLM近似概率分布。

混合架构——LLM作为语义和综合接口，物理模拟器作为因果推理引擎——很可能是电力系统工程工具演进的方向。其发展将需要与本学位论文工作流程结构相同的认识论警惕：始终清楚每个工具做什么，以及明确要求它不做什么。

所使用的限制性提示流的详细记录，以及所应用修正的代表性示例，记录在[附录九 · 方法论与模型](./anexo-metodologia-modelos-datos-vivos.mdx)中，遵循将生成式模型整合到本科和研究生研究中的方法论透明度标准。
