本学位论文的撰写是在一个非典型的方法论背景下进行的：在2024-2026两年间，伊比利亚电力系统同时遭遇系统性危机，而自然语言处理工具也经历了加速变革。能够几分钟内处理数百页技术文档的大型语言模型（LLMs）的可用性，恰逢一年内发布了四份主要专家报告和十余篇关于同一事件的学术分析。本章将透明地记录这些工具是如何被整合的，它们具体执行了哪些任务，检测并纠正了哪些系统性错误，以及由此对工程研究实践产生的认识论反思。

## 方法论应用：五项操作功能

起始文献主体包括技术档案、ENTSO-E法规、超过200页的官方报告、IIT-ICAI的PSS/E仿真、CNMC会议纪要、NREL的波形记录以及大量的专业新闻资料。在没有计算机辅助的情况下进行线性阅读，与学位论文的学术期限不相容。生成式模型的整合围绕五个明确界定的操作功能展开，其中任何一个都不涉及对系统物理的自主因果推理：

工作流程分为三个连续阶段，并带有一个校正循环：

```text
[主要来源] ──> [大语言模型辅助] ──> [物理验证过滤器] ──> [论文正文]
                             ▲                              │
                             └──────────────────────────────┘
                               (检测到幻觉时重新制定提示词)
```

方法论上决定性的因素不是大语言模型辅助本身，而是介于模型任何输出与将其纳入文本之间的物理验证过滤器：基尔霍夫定律、Q-V曲线、转子摆动方程以及与主要来源的核对。当过滤器检测到与系统力学不相容的推理时，会使用额外的语义约束重新制定提示词，并重新开始循环。

## 验证与核实：四个错误推理案例

在像电力系统动力学这样因果关系密集的领域中使用生成式模型，会系统地揭示出一种电力系统无法容忍的行为：基于统计类比进行推理。大语言模型倾向于将“典型”的因果模式——其训练语料库文献中最常见的模式——应用于物理结构“非典型”的案例。4月28日事件，由于其双重性质（电压稳定而非频率平衡），相对于20世纪技术文献中记录的大多数停电事故而言，是一个非典型案例，这使得观察人工智能“默认”偏离真实现象的点变得特别富有成效。

### 低频减载悖论案例

最典型的错误模式案例：当被问及减载在事件发展中的作用时，模型系统性地提供了从经典停电事故中继承的解释，在这些事故中，低频减载是最后一道防线，并且通常通过恢复频率-有功功率平衡来成功保留部分电网。这种推理对于模型训练所依据的事件集合在物理上是正确的，但对于4月28日事件无效：在一个由Q-V平面主导的崩溃中，低频减载的激活同时移除了被断开负载所提供的感性无功功率吸收点，从而加剧了过电压，而非缓解它。

纠正需要制定一个带有明确分析平面约束的提示词，并手动验证由此产生的推理是否与NREL在12:33:19–12:33:27 CEST时间段内发布的波形图一致（[*参见交互式相图模拟器*](./anexo-interactivos#phaseplane)）。

### 分接头滞后案例

模型对有载调压变压器的定性描述在稳态下是正确的，但默认假设了实际机电组件不具备的比例和瞬时响应。为避免追逐而有意引入的延迟，在4月28日事件中转化为相对于电气暂态过程滞后的变比，从而向220千伏和132千伏网络倍增了过电压——这是操作员SCADA系统无法察觉的现象，因为它锚定在400千伏一次侧的测量值上。分接头滞后的整个因果链要求事先向模型描述有载调压变压器的时间常数，并禁止其假设准瞬时响应。

### 电网容性贡献案例

估计注入的1,050兆乏容性无功必须对应于400千伏线路在空载状态下运行时的并联导纳（$Y_t$）效应（费兰梯效应）。验证包括在线路π型模型上重现无功平衡，并将数量级与波形图以及IIT-ICAI报告的诊断结果进行对比。

### 0.6赫兹振荡案例

这说明了在存在机构分歧的法医背景下使用人工智能的一个特定局限性。模型倾向于产生一个综合响应——对来源进行平均后得到的“最可能”解读——而专业严谨性要求保留分歧。该模式的起源正是本论文需要作为未解决的分歧呈现的数据点，而非作为编辑共识。

### 网络拓扑案例（因数据缺失导致的幻觉）

这个案例揭示了一个根本性的脆弱性：大语言模型被设计用于完成模式。由于特定逆变器控制回路和变电站拓扑的确切细节因关键安全原因而不属于公共领域，模型通过生成“典型”但虚构的网络架构来填补信息空白，从而产生了结构性幻觉。人工智能无法从互联网上的通用数据推断出封闭关键基础设施的现实。

这五个案例可以得出一个普遍性观察：自动辅助在“处理”任务中效用最大——提取、综合、结构化、制表、辅助写作——而在涉及训练语料库中代表性不足的物理现象的“因果推理”任务中效用最小，甚至可能适得其反。

## 批判性反思：工程研究中的AI

所记录的经验得出一个结构性的结论，既非胜利主义也非灾难主义：生成式模型是研究者认知过程的强大加速器，但它们基于概率逻辑运作，这与支配物质系统物理的决定性逻辑并不一致。

### 方法论含义

使用人工智能并不能免除研究者掌握其研究对象的专业技术内容；相反，它对此提出了更严格的要求。只有具备足够技术能力来识别物理上不可能的推理的研究者，才能安全地使用一个能够以流畅修辞产生这种推理的模型。输出结果的语言可信度与其物质正确性之间的不对称，构成了在这些工具用于要求严格的技术领域时的主要风险，并且只能通过工具本身无法提供的对内容的掌握来中和。

### 伦理-学术含义

在本工作中，自动辅助被用作处理工具，而非推理的替代品。所有内容决策——问题的框架、来源的层级、关于4月28日崩溃的因果论点的表述、对机构叙述的比较评估、最终结论——完全是作者的责任。人工智能不会签署学位论文，也不会坐在答辩委员会面前：工程师以其名义为所陈述事实的物质因果关系背书，这种背书是不可转让的。

### 前瞻性学科含义

未来十年的电力系统——以电力电子为主导，具有子周期尺度的相关动态，以及常规操作员无法实时捕获的电压-无功相互作用——将需要结合算法模型处理速度与PSS/E类仿真器物理鲁棒性的决策支持工具。这种整合并非易事：仿真器求解方程；大语言模型近似概率分布。

混合架构——大语言模型作为语义和综合接口，物理仿真器作为因果推理引擎——很可能是电力系统工程工具演进的方向。其发展将需要与本论文工作流程结构相同的认识论警惕：始终清楚每个工具做什么，以及明确要求它不做什么。

所使用的限制性提示词流程的详细记录，以及所应用校正的代表性示例，将在AI方法论附录中记录，遵循关于在本科和研究生研究中整合生成式模型的方法论透明度最佳实践建议。
