4月28日的电力崩溃不仅仅是一次技术基础设施故障：
它是一次实证，表明现代社会是高度相互依存的系统，
其中能源、电信、水、交通和医疗构成了一个网络中的网络。
当第一个倒下时，其余的便随之级联崩溃。

## 1. 应急系统的响应

### 西班牙：宣布国家利益紧急状态

停电的规模迫使最高机构层面做出响应。内政部根据
第17/2015号《国家民防系统法》第28条，通过
INT/399/2025号命令启动了国家利益紧急状态声明，
随后通过INT/400/2025号命令将其扩展至
卡斯蒂利亚-拉曼恰、加利西亚和巴伦西亚自治区。

## 2. 对医院和医疗服务的影响

### 能源分诊

在大多数医院，发电机组在最初15分钟内启动，
保护了ICU、正在手术的手术室和生命支持设备。
然而，鉴于停电持续时间的不确定性，医院管理层
执行了能源分诊政策：暂停择期手术、
门诊咨询和辅助服务，以延长燃料储备。

<ForensicReveal
  l1="停电两小时后，几家葡萄牙医院的柴油即将耗尽。"
  l2="医院柴油发电机是为持续几小时的局部停电设计的，而非同时使供应链崩溃的区域性停电。同时为多家医院补给燃料，而加油站没有电力抽取燃料，街道因交通堵塞，这在后勤上几乎是不可能的。"
  l3="ANEPC国家指挥官Mário Silvestre在议会委员会上声明，最令人震惊的发现是，停电开始仅两小时后，就有医院的燃料储备完全或几乎耗尽。在道路崩溃条件下同时进行补给的后勤构成了国家安全挑战。"
  source="ANEPC / 议会调查委员会（葡萄牙，2025年）"
/>

### 伤亡与谣言

在受保护的临床环境中没有记录到死亡。
关于托莱多、阿尔瓦塞特、巴伦西亚和奥伦塞医院有死亡的大规模谣言流传
——被这些中心的管理层坚决否认——。官方统计是与停电间接相关的8例死亡：

- 一氧化碳中毒：在封闭不通风的空间使用家用发电机。
- 火灾：应急照明蜡烛倾倒。
- 家用医疗设备故障：设备缺乏医院环境的严格维护。

:::danger 确认死亡 — 葡萄牙
一名77岁的女性，24小时依赖家用机械通气，
在呼吸机电池耗尽后死亡。电话网络崩溃
阻止了INEM（国家医疗急救研究所）及时收到求救电话。
:::

## 3. 交通基础设施瘫痪

### 铁路网络：35,000人被困

13:13 CEST，ADIF和RENFE确认整个半岛铁路交通中断。
大约35,000名乘客被困在停在露天轨道和地铁隧道中的列车上
（马德里、巴塞罗那、里斯本）。

### 模拟广播的复兴

在历史上最数字化的社会中，FM是当局与公民之间唯一的
信息纽带。西班牙国家广播电台（RNE）从拥有自身柴油发电机的
基础设施中持续播报简报，防止了通常伴随长期信息真空的
社会恐慌。

## 5. 水-能源纽带

### 饮用水处理厂、污水处理厂和泵站

电力归零后几分钟，大型环境工厂失去动力。
饮用水处理厂（ETAP）、污水处理厂（EDAR）和
大容量泵站瘫痪。

<ForensicReveal
  l1="在几个地区，停电后几小时水龙头就不出水了。"
  l2="现代城市供水并非纯靠重力：需要电动泵来克服地形并保持压力。没有电力，管网压力在几分钟内下降。在高海拔社区，断水是即时的。"
  l3="在穆尔西亚地区和托莱多，可用流量监测到减少了70%。巴塞罗那的奥尔塔-吉纳尔多区经历了超过18小时的饮用水中断。葡萄牙水务公司发布了‘极度节制’用水的警报。污水处理厂的停运使受纳流域面临直接未经处理排放的风险，如果事件持续超过24小时。"
  source="葡萄牙水务公司 / 巴塞罗那市政府 / ANEPC分析"
/>

### 28A后的响应

停电加速了两项公共政策倡议：

1. 城市水循环数字化PERTE（>5.5亿欧元）：管网分区、智能传感、预测性泄漏控制。
2. 污水处理厂能源自消费：推广污泥厌氧消化制沼气。西班牙水务部门已年产约787 GWh生物能源 — 目标：自给自足并脱离电网。

## 6. 对弱势群体的不对称影响

### 电依赖者：看不见的鸿沟

受影响最严重的群体是其生理机能与交流电紧密相连的人：
持续机械呼吸机、制氧机、输液泵、家庭血液透析。

<ForensicReveal
  l1="拥有家用医疗设备的人在停电期间完全被遗弃。"
  l2="与医院不同，私人住宅没有发电机组。家用设备依靠电网或内部电池运行，续航仅几小时。没有主动的电依赖者官方登记册，无法优先提供便携式发电机。"
  l3="ALCER联合会记录到，家庭血液透析患者无法联系其肾病医生，因为电话网络已崩溃。治疗被重新安排到电力恢复后的凌晨，避免了直接死亡。一个记录在案的案例：一个脑瘫儿童的家庭将制氧机连接到家庭面包车的电池上以维持其生命。"
  source="ALCER联合会 / ANEPC / 28A后护理文件"
/>

### 聋人：完全孤立

西班牙聋人联合会（CNSE）正式投诉称，
紧急信息系统的信息完全偏向通过模拟广播的口头消息。
随着电视地面数字信号和互联网接入的崩溃，
聋人社区陷入了完全的信息隔离状态，
没有关于原因、危险或预测的指导。

### 电梯被困

葡萄牙ANEPC记录了全国范围内超过400起
人员被困电梯的同步事件，消耗了消防部门
本应用于其他更大紧急情况的资源。

## 结论：相互依存作为系统性脆弱性

对停电最初18小时的部门分析表明，现代社会的韧性不能通过每个基础设施的单独稳健性来衡量，而应通过相互依存链中最薄弱环节的强度来衡量。28-A揭示，这个环节是电能：其缺失引发了电信、交通、医疗、水和食品安全方面的级联故障，将崩溃的影响放大到远超供电中断本身。已启动的改革 — 警报系统现代化、关键基础设施的能源自主性、创建电依赖者登记册 — 构成了必要但不完全的回应：28-A的结构性教训是，韧性规划必须是跨部门的，而非部门性的。
