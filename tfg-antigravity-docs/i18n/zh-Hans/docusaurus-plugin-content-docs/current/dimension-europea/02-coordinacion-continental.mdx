伊比利亚半岛与欧洲大陆同步系统的突然分离，不仅仅是一次基础设施事故：它是2006年欧洲大停电后设计的泛欧电网治理体系在真实条件下的首次测试。本章记录了该制度架构从崩溃的最初几秒到最终重新同步的响应过程——其速度、成就与局限。

## 同步区域监视器（SAM）：统一指挥的激活

ENTSO-E的治理架构指定同步区域监视器（SAM）在威胁欧洲大陆完整性的事件中承担宏观协调控制。2025年4月，这些角色由瑞士电网（Swissgrid）和德国安普利翁（Amprion）承担。4月28日西班牙、葡萄牙和法国的突发事件直接属于瑞士电网的监督范围。

ENTSO-E预警系统（EAS）——一个加密、集中化的通信平台——作为危机管理的神经系统运行。调度记录揭示了超国家统一指挥结构建立的速度：

关键窗口位于12:49至12:54 CEST之间：在短短五分钟内，SAM应用了ENTSO-E标准化的系统分离协议，分配了三个具有排他性且不重叠权限的不同角色：

REE — 伊比利亚频率领导者。在隔离区块内平衡发电/用电关系的专属任务，管理减载和逐步启动，不受外部干扰。

Swissgrid — 欧洲大陆频率领导者。控制同步区域的其余部分，协调20多个国家的频率遏制备用（FCR），以补偿因失去对半岛的出口以及Baixas HVDC关闭而产生的突然过频。

RTE — 再同步领导者。对跨比利牛斯山联络线的闭合操作拥有绝对权力。未经RTE在巴黎和图卢兹控制室对滑差和电压参数的预先验证，REE或任何其他实体不得操作边境开关。

## Coreso的角色：恢复的数学盾牌

当国家输电运营商操作物理开关时，区域协调中心（RCC）Coreso（布鲁塞尔）执行着巨大的计算工作，以确保危机解决方案不会引发新的停电。

随着下午的推进，从法国到西班牙的紧急电力输送规模上升，最终协商了高达2000 MW的临时进口。这些大规模注入严重改变了法国、瑞士和德国电网沿线的自然负荷潮流。Coreso利用协调安全分析（CSA）工具，在欧洲统一模型（CGM）上近乎实时地处理交流潮流。

其目标是验证严格遵守N-1准则：通过模拟证明，如果当法国出口这2000 MW支持时，法国或德国的一条内部走廊突然丢失，剩余的互联电网不会遭受热过载或电压越限。同时，北欧RCC领导了短期充裕性分析（STA），向SAM确认中欧存在可用的旋转备用容量，以维持这一努力，而不会危及捐赠国的夜间高峰需求。

Coreso的这一验证是使RTE能够以战术信心操作的数学盾牌。没有它，不稳定性从半岛向大陆电网核心传播的风险将迫使严格限制支持，从而减缓恢复。

## EAS无法掩盖的局限性

一旦紧急状态被激活，多国协调以显著的效率运作。然而，这一事件残酷地暴露了欧洲监测系统在前期阶段的结构性局限：正如西班牙系统分析中所记载的，伊比利亚区块直接从“正常”状态过渡到“停电”状态（OB3标准），跳过了《系统运行指南》中规定的中间“警报”或“紧急”状态。

结果是，邻近的运营商——RTE、Swissgrid、Coreso——没有收到比利牛斯山脉以南动态脆弱性的预警信号。

SAM/EAS架构的首次行动不是预防性的，而是反应性的：EAS充当了崩溃的事后通知者，而不是早期预警工具。这一局限性——欧洲监测系统无法捕捉低惯性电网中快速电压动态——是该事件的核心监管教训之一，也是下一节记录改革的起点。

通信一直保持到紧急状态结束，最终于4月29日00:11 CEST，RTE通知Swissgrid，REE的自动发电控制（AGC）算法已重新稳定闭环——这一信号证明大陆紧急状态结束。
