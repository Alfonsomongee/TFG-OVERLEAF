:::note 四位专家之间坚实的技术共识
对比四种叙述，出现了三个任何专家报告都无法反驳的共识点：

首先，崩溃的主要机制并非因惯性不足导致的频率损失，而是由残余同步发电量最小化与需求低谷期间400 kV线路轻载共同引发的容性状态下的电压失稳。

其次，在“轻载网络”状态下长时间运行，非同步发电瞬时渗透率达到82%，已在数周前结构性耗尽了动态电压控制裕度，4月22日和24日的前兆事件即为明证。

第三，截至4月28日生效的监管框架——具有非对称死区的P.O. 7.4、未要求构网型（Grid-Forming）的NC RfG——在瞬态过程所需的时间范围内，结构性不足以调动缓冲资源。
:::

分歧将机构间的差异清晰地组织成两个轴线。

测量范围轴线。CSN委员会和REE将惯性计算为整个半岛系统的全局量（2.3秒），而IIT-ICAI和NREL的报告则使用分解的区域值（南部地区为1.3秒）。这两个值在算术上都是正确的，但在实质上不同：4月28日事件并非平均值的失效，而是局部应力下最薄弱区域的失效。<KeyFact id="inercia-28a" mode="callback">H = 平均值2.3秒 / 南部地区1.3秒 — 第2章</KeyFact>

触发因素归因轴线。CSN委员会和REE将焦点放在发电厂无功吸收不足上——这是P.O. 7.4规定的义务主体的疏忽。IIT-ICAI则将其归因于系统运营商的合环操作以及Tap-Lag对220 kV电网的结构性不可观测性——一项运营决策和一种工具限制。这两种诊断都与示波器证据兼容：超过2.4 GVAr的容性瞬态过程同时需要一个引发它的决策和一种无法遏制它的响应能力。分歧不是技术性的，而是分配性的：它涉及在因果关系链中的责任归属，所有报告都承认这一链条。

综合来看，这四种叙述并非对同一事件相互排斥的解释，而是对同一多层现象在不同分析框架和机构责任范围内的部分投影。解释上的分歧并非需要解决以支持某一立场的噪音：它本身就是一个法医数据，揭示了现代电力系统的动态复杂性如何超越任何单个主体对事件进行全面重构的能力。

## 结构性影响：能源转型三难困境的解决

正如本调查开始时介绍并在技术、监管和市场分析的每个阶段逐步阐述的那样，4月28日的崩溃不能被视为随机事故，而是**能源转型三难困境**的经验性和终极性体现。欧洲转型中未解决的结构性紧张关系在那个早晨同时结晶。脱碳不是崩溃的原因：它是边界条件，由于未能在技术、监管和经济层面进行对称适应，将潜在脆弱性转化为事故。

### 技术紧张关系

实际发电厂与系统在IBR主导模式下安全运行所需发电厂之间的差距。用构网型拓扑逆变器取代大型同步发电机，使电网失去了旋转机械无需明确报酬即可提供的两项服务：真正的旋转惯性和维持输电网络节点短路比所需的短路功率。专家报告趋同的技术退出方案，结合了具有构网型能力的分布式电池储能系统部署，用于次周期电压管理，以及选择性安装同步调相机，包括对已关闭化石燃料电厂发电机的棕地改造。

### 监管紧张关系

继承的运营框架在管理动态加速电网方面的不适应性。通过2025年6月12日CNMC决议对P.O. 7.4的更新——包含明确的动态要求并首次允许IBR和储能在电压控制服务中发挥作用——是朝着正确方向迈出的一步。然而，2025年10月将合规阈值从75%提高到90%的提案被驳回，突显了新资产能力与被其取代的同步电厂能力之间的时间不对称性。在欧洲层面，ENTSO-E第二阶段技术报告（2025年11月）中构网型要求的巩固及其对未来NC RfG 2.0的影响，构成了后碳电网的技术框架——尽管欧盟委员会目前对采纳时间表的降级处理引入了一个不确定性窗口，各国运营商正通过电网代码之外的过渡措施来弥补。

### 经济紧张关系

专家报告指出这是技术重新设计可行性的最终制约因素。纯粹的边际主义能源模型在结构上无法补偿维持稳定性的系统属性：惯性、短路功率、动态无功和快速频率响应。零或负电价小时数的激增——2024年超过500小时，4月28日当天平均日价格为18.50欧元/兆瓦时——并非可再生能源设计的缺陷，而是稳定性属性在市场竞争目标函数中缺失的信号。将这些服务转化为明确的商业产品，在增强型响应服务类别下，是使前述技术和监管框架在中期内具有可持续性的经济前提。

在欧洲治理层面，该事件凸显了欧洲意识系统作为早期预警功能的局限性。伊比利亚系统从“正常”状态过渡到“停电”状态，而未经过系统运行指南中预设的中间状态。其含义是结构性的：基于静态潮流分析和N−1准则构建的安全工具，对于高电力电子渗透率的电网是不适用的，因为其相关动态发生在亚秒级时间尺度上。泛欧协调架构需要纳入节点强度动态指标、区域惯性指数和构网能力指标，作为输电系统运营商之间可互认的状态参数。

## 4月28日的教训

从整体上看，4月28日的结构性教训并非能源转型过于雄心勃勃，也非脱碳危及供应安全。教训是，要使转型在运营上可持续，它必须在三难困境所识别的三个层面——技术、监管和经济——同时发生。它们之间的任何不对称——一个已转型的发电厂配上继承的电网代码；一个更新的电网代码却没有市场来补偿其所要求的服务；一个重新设计的市场却没有能够提供这些服务的物理资产——都会重现4月28日事件所体现的脆弱性条件。

这项工作的分析价值最终在于表明，四种机构叙述共存而不相互抵消，并且它们中的任何一个单独来看都无法穷尽对事件的理解。法医综合要求将专家报告视为对同一复杂现象在不同主体各自框架下的部分投影，而非关于同一事件的竞争性假设。只有三角化解读——保留分歧而非消解分歧——才能提取出将深度脱碳的常规运营场景转变为二十年来大陆同步区域首次系统性停电的结构性条件。

这些条件远非特殊，而是存在于每一个处于转型中的欧洲电力系统中：从这个意义上说，2025年4月28日与其说是一次伊比利亚事故，不如说是一个欧洲先例。
