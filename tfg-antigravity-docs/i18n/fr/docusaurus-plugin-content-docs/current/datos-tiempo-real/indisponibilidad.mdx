# Indisponibilité du Réseau de Transport

Degré d'affectation physique du réseau maillé de transport à haute tension (400 kV) lors de la succession de déclenchements par surtension, reflétant le volume de sous-stations et de lignes temporairement mises hors tension par les protections du système.
