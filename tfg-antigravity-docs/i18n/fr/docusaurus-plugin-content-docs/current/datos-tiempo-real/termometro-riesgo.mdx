# Thermomètre de Risque

Estimation en temps réel du niveau d'inertie équivalente et de la pénétration renouvelable instantanée dans le système synchrone péninsulaire. Le modèle compare l'état opérationnel actuel aux seuils critiques de stabilité calculés après la déconnexion du 28 avril (limite opérationnelle inférieure fixée à 2,3 GW·s).
