# Impatto Economico del Blackout

Ripartizione analitica dei costi e delle responsabilità finanziarie derivanti dalla disconnessione di massa del 28 aprile. Vengono considerate la valutazione dell'energia non fornita (VoLL), l'iniezione forzata di generazione di backup con cicli combinati a gas e i costi diretti per danni agli asset del sistema.
