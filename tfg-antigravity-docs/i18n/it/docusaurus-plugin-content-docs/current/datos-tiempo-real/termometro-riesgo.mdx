# Termometro del Rischio

Stima in tempo reale del livello di inerzia equivalente e della penetrazione rinnovabile istantanea nel sistema sincrono peninsulare. Il modello confronta lo stato operativo attuale con le soglie critiche di stabilità calcolate dopo la disconnessione del 28 aprile (limite operativo inferiore situato a 2,3 GW·s).
