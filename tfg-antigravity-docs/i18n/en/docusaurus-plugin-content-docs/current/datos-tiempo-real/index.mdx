:::info Methodological statement: live data section

This section displays **current operational data** from the Iberian electricity system obtained from the ESIOS API (Red Eléctrica de España) with updates every 5 minutes.

**It is not part of the historical forensic reconstruction of the blackout on April 28, 2025.** The comparative analysis modules show fixed historical data from April 28 for contextual reference, but the main purpose is live monitoring of systemic variables.

For the causal analysis of the event and its technical determinants, consult Chapters 2–4 (Context, Analysis, Reaction) and the technical documentary appendices.

:::
