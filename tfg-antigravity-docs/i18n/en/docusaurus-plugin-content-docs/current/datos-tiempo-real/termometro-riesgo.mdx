# Risk Thermometer

Real-time estimation of the equivalent inertia level and instantaneous renewable penetration in the peninsular synchronous system. The model compares the current operating state with the critical stability thresholds calculated after the disconnection on April 28 (lower operating limit set at 2.3 GW·s).
