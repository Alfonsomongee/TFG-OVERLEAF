# Risk Thermometer

Real-time estimation of the equivalent inertia level and instantaneous renewable penetration in the peninsular synchronous system. The model compares the current operational state with the critical stability thresholds calculated after the April 28 disconnection (lower operational limit set at 2.3 GW·s).
