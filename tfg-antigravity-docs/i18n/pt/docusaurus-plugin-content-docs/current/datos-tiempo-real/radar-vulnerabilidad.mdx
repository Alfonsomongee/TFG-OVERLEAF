# Radar de Vulnerabilidade

Análise multidimensional de cinco fatores operativos determinantes do risco de instabilidade transitória de tensão. Este indicador geométrico mede em tempo real a distância euclidiana do vetor operativo atual em relação ao padrão característico do colapso de 28-A.
