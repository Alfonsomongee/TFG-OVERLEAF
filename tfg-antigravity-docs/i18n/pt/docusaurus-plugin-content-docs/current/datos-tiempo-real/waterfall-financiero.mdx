# Impacto Econômico do Apagão

Detalhamento analítico dos custos e responsabilidades financeiras decorrentes da desconexão massiva de 28 de abril. Contemplam-se a avaliação da energia não fornecida (VoLL), a injeção forçada de geração de reserva com ciclos combinados a gás e os custos diretos por danos a ativos do sistema.
