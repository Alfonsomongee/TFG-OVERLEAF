# Termômetro de Risco

Estimativa em tempo real do nível de inércia equivalente e penetração renovável instantânea no sistema síncrono peninsular. O modelo compara o estado operativo atual com os limiares críticos de estabilidade calculados após a desconexão de 28 de abril (limite operativo inferior situado em 2,3 GW·s).
