April erfordert den Abgleich der Schlussfolgerungen des Regierungsausschusses, von ENTSO-E und externen Beratern (Compass Lexecon), wobei Datenasymmetrien durch die Verwendung hochauflösender PMU-Aufzeichnungen aufgelöst werden.   </AnnexThesisBox>
