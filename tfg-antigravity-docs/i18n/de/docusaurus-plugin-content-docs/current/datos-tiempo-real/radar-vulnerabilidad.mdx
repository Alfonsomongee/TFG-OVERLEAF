# Vulnerabilitätsradar

Multidimensionale Analyse von fünf operativen Faktoren, die das Risiko einer transienten Spannungsinstabilität bestimmen. Dieser geometrische Indikator misst in Echtzeit den euklidischen Abstand des aktuellen Betriebsvektors zum charakteristischen Muster des Zusammenbruchs vom 28. April.
