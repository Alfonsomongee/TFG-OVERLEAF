# Vulnerabilitätsradar

Multidimensionale Analyse von fünf operativen Faktoren, die das Risiko einer transienten Spannungsinstabilität bestimmen. Dieser geometrische Indikator misst in Echtzeit die euklidische Distanz des aktuellen operativen Vektors vom charakteristischen Muster des Zusammenbruchs vom 28. April.
