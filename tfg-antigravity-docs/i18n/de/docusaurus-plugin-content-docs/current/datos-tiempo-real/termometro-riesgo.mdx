# Risikothermometer

Echtzeitschätzung des äquivalenten Trägheitsniveaus und der momentanen erneuerbaren Durchdringung im synchronen Festlandnetz. Das Modell vergleicht den aktuellen Betriebszustand mit den kritischen Stabilitätsschwellen, die nach der Trennung vom 28. April berechnet wurden (untere Betriebsgrenze bei 2,3 GW·s).
