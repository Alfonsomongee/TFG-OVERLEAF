# Risikothermometer

Echtzeitschätzung des Niveaus der äquivalenten Trägheit und der momentanen Durchdringung erneuerbarer Energien im synchronen Halbinselsystem. Das Modell vergleicht den aktuellen Betriebszustand mit den kritischen Stabilitätsschwellen, die nach der Abschaltung vom 28. April berechnet wurden (unteres Betriebslimit liegt bei 2,3 GW·s).
