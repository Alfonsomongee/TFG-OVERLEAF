# Nichtverfügbarkeit des Übertragungsnetzes

Grad der physischen Beeinträchtigung des vermaschten Hochspannungs-Übertragungsnetzes (400 kV) während der Abfolge von Überspannungsauslösungen. Dies spiegelt das Volumen der Umspannwerke und Leitungen wider, die vorübergehend durch die Systemschutzvorrichtungen abgeschaltet wurden.
