# Wirtschaftliche Auswirkungen des Stromausfalls

Analytische Aufschlüsselung der Kosten und finanziellen Verantwortlichkeiten, die sich aus der massiven Abschaltung vom 28. April ergaben. Berücksichtigt werden die Bewertung der nicht gelieferten Energie (VoLL), die erzwungene Einspeisung von Reserveerzeugung mit Gas-und-Dampf-Kombikraftwerken sowie die direkten Kosten durch Schäden an Systemanlagen.
