<GlitchTitle>Technisches Glossar</GlitchTitle>

:::note
Dieses Glossar enthält die wichtigsten technischen Begriffe der Analyse des 28. April, definiert auf der Grundlage von Normen, Netzcodes und technischer Referenzliteratur, einschließlich IEEE Std 2800-2022, ENTSO-E NC RfG, CIGRE und Kundur (1994). Jeder Begriff umfasst seine formale Definition, seine normative oder bibliografische Referenz, seine spezifische Relevanz für den iberischen Zusammenbruch sowie erweiterte technische Details.

Für eine umfassendere Abdeckung der Terminologie – etwa 119 Begriffe – bietet das schwebende Panel, das beim Überfahren mit der Maus oder beim Aktivieren der unterstrichenen Begriffe im Text jedes Kapitels erscheint, kontextbezogene Definitionen während des Lesens.
:::
