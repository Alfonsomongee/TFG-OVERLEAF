REDIRECCIONES Y ROUTING
================================================================================

Redirecciones en vercel.json (probable):

```json
{
  "rewrites": [
    {
      "source": "/en",
      "destination": "/en/introduccion"
    },
    {
      "source": "/en/",
      "destination": "/en/introduccion"
    },
    {
      "source": "/de",
      "destination": "/de/introduccion"
    }
  ]
}
```

Propósito:
  - Usuario entra /en → redirige a /en/introduccion
  - User entra /de → redirige a /de/introduccion
  - Evita landing en página vacía

SLUGS CUSTOM:
  Algunos documentos pueden tener slug custom en frontMatter
  Ejemplo:
    slug: /analisis-incidente-28-abril
  → URL diferente del nombre de archivo

PÁGINAS DINÁMICAS (DATOS EN TIEMPO REAL)
================================================================================

Directorio: docs/datos-tiempo-real/
Archivos: 12 documentos autogenerados

CARATERÍSTICA ESPECIAL: Contenido dinámico
  - Cada página fetch data de ESIOS API
  - Hook: useEsiosAnalysis
  - Análisis LLM generado en tiempo real

Comportamiento:
  - Carga inicial: muestra skeleton/loading
  - API call: fetch /api/esios-multi
  - Análisis: POST a /api/esios-analysis
  - Render: actualiza cada 5 minutos (setInterval)

Componentes:
  - MixGeneracion (con useEsiosAnalysis ✓)
  - DemandaRenovableTrend
  - BalanceIntercambios
  - PrecioSpotScatter
  - RadarVulnerabilidad (con useEsiosAnalysis ✓)
  - TermometroRiesgo (con useEsiosAnalysis ✓)

RIESGO: Si API cae, estos componentes muestran error/skeleton

COMPORTAMIENTOS ESPECIALES EN PÁGINAS
================================================================================

1. ZEN MODE:
   Toggle localStorage.zen-mode
   Afecta todas las páginas
   ¿Qué se oculta?
   - Navbar (hideOnScroll)
   - Sidebar
   - Footer
   - TOC

2. DARK/LIGHT MODE:
   Toggle via navbar (probablemente)
   Persistent en localStorage (data-theme)
   Afecta todas las páginas

3. LANGUAGE SELECTOR:
   Dropdown en navbar
   Cambia todas las páginas a idioma seleccionado
   URLs: /es/, /en/, /de/, /zh-Hans/

4. SEARCH:
   Hotkey Ctrl+K abre búsqueda
   Funciona en todas las páginas
   Resultados son multiidioma
