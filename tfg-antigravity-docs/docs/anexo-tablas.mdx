<AnnexSection
  id="lectura-tablas"
  eyebrow="Lectura del anexo"
  title="Cómo interpretar las tablas"
  description="Las tablas combinan registros históricos, síntesis analíticas y una base maestra de datos."
  defaultOpen={true}
>

Cinco criterios de lectura para este banco tabular:

- **Dato medido frente a reconstrucción.** Algunas magnitudes proceden directamente de mediciones instrumentales (PMU, SCADA, oscilógrafos); otras son valores inferidos o reconstruidos a partir de varios informes. Las tablas indican la fuente primaria cuando el valor es medido directamente.

- **Magnitudes con incertidumbre.** Varios valores presentan discrepancias entre fuentes (p. ej., potencia perdida en el inicio de la cascada). En la base maestra, el campo *Nota de Discrepancia* documenta estos casos con el valor alternativo registrado.

- **N/A no significa cero.** El valor N/A indica que el dato no está disponible o no es aplicable en el contexto de esa fila. No debe interpretarse como ausencia de fenómeno ni como valor nulo.

- **MW, MWh, MVAr y euros no son intercambiables.** Cada tabla usa la unidad del sistema de medida pertinente. Mezclar potencia activa (MW), energía (MWh), potencia reactiva (MVAr) e impacto económico (€) sin conversión genera errores de interpretación.

- **Las tablas largas se conservan en este anexo.** Para no saturar los capítulos principales, las tablas con más de 10 filas o con datos de contraste detallados se extraen aquí. Los capítulos incluyen solo las magnitudes clave, con referencia explícita a las tablas del Anexo B.
