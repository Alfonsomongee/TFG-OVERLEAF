# Termómetro de Riesgo

Estimación en tiempo real del nivel de inercia equivalente y penetración renovable instantánea en el sistema síncrono peninsular. El modelo compara el estado operativo actual con los umbrales críticos de estabilidad calculados tras la desconexión del 28 de abril (límite operativo inferior situado en 2,3 GW·s).
