Esta sección muestra **datos operativos actuales** del sistema eléctrico ibérico obtenidos de la API de ESIOS (Red Eléctrica de España) con actualización cada 5 minutos.

**No forma parte de la reconstrucción forense histórica del apagón del 28 de abril de 2025.** Los módulos de análisis comparativo mostran datos históricos fijos del 28-A para referencia contextual, pero el propósito principal es la monitorización viva de variables sistémicas.

Para el análisis causal del evento y sus determinantes técnicos, consulten los Capítulos 2–4 (Contexto, Análisis, Reacción) y los Anexos técnicos documentales.

:::
