Interlineado:
  --lh-tight: 1.05   (titulares comprimidos)
  --lh-snug:  1.2    (subtítulos)
  --lh-body:  1.65   (espaciado generoso para legibilidad)

Tracking (letter-spacing):
  --tr-tight: -0.03em  (comprimido)
  --tr-loose: 0.12em   (expandido)

VENTAJAS:
  ✓ Escala basada en perfect fourth (1.333)
  ✓ Responsive sin media queries (viewport-driven)
  ✓ Legibilidad mantiene proporción en todos los tamaños

PROPUESTA DE LECTURA PARA OPUS
================================================================================

1. ARQUITECTURA CSS:
   - Single custom.css file (~3773 líneas)
   - Importa designTokens.css para variables compartidas
   - Sin Tailwind ni PostCSS (vanilla CSS moderno)

2. SISTEMA DE VARIABLES:
   - CSS custom properties (--variable-name)
   - Jerarquía clara: --accent-*, --bg-*, --text-*, --chart-*
   - Sobrescribibles por data-theme attribute

3. DUAL THEME:
   - Dark mode: azul oscuro + cian (cyberpunk)
   - Light mode: papel cálido + burdeos (editorial vintage)
   - Toggle sin reload (CSS-only, no JS adicional)

4. TIPOGRAFÍA RESPONSIVA:
   - clamp() para escalas fluidas
   - Fuentes: Space Grotesk (display), Inter (body), JetBrains Mono (code)
   - Interlineado generoso para legibilidad

5. COMPONENTES CUSTOMIZADOS:
   - .esios-analysis-block para análisis LLM
   - Probable: .sidebar-icon-* para iconografía
   - Probable: .glitch-* para efectos de datos anómalos

6. PATRONES DE MANTENIMIENTO:
   - Variables CSS centralizadas → cambio de tema = cambiar 3-5 variables
   - Escala tipográfica con clamp() → responsive sin media queries
   - Dark/light overrides en selectores data-theme
