================================================================================
QUÉ ES THEME SWIZZLING
================================================================================

Docusaurus permite "swizzling" (ejeción controlada) de componentes de tema.
Los componentes swizzled son copias locales que sobrescriben los defaults.

Ventajas:
  ✓ Control total sobre renderizado
  ✓ Inyección de lógica custom
  ✓ Preservación en git (no depende de versión de Docusaurus)

Desventajas:
  ⚠ Rompe automáticamente con upgrade de Docusaurus
  ⚠ Requiere mantenimiento manual
  ⚠ Puede introducir bugs si no se sincroniza con upstream

IMPACTO DE SWIZZLES EN ACTUALIZACIONES
================================================================================

Riesgo por versión de Docusaurus:

Docusaurus actual: 2.4.3
Cambios upstream en 2.5.0+:
  - Nuevos componentes pueden no mapearse
  - Props pueden cambiar
  - Hooks deprecated pueden causar warnings

RECOMENDACIÓN:
  - Documentar versión de Docusaurus de cada swizzle
  - Considerar unswizzle de componentes que no se modifican mucho
  - Mantener changelog de cambios en swizzles
