RESUMEN ARQUITECTURA
================================================================================

STACK TECNOLÓGICO:
  - Framework: Docusaurus 2.4.3 (Next.js based)
  - React: 17.0.2
  - CSS: custom.css + CSS Modules + inline styles
  - Búsqueda: Lunr (offline, multiidioma)
  - Matemáticas: KaTeX (vía CDN)
  - Datos: Multiples librerías (Plotly, ECharts, Recharts, Deck.gl)
  - Mapas: MapLibre GL
  - Animación: GSAP + Framer Motion
  - Deploy: Vercel
  - LLM: Anthropic Claude SDK (para chatbot)

CARACTERÍSTICAS GLOBALES:
  - Multiidioma (es/en/de/zh-Hans) con dropdown en navbar
  - Zen-mode toggle (localStorage-based, inline script)
  - Buscador offline Lunr
  - Resaltado de código con Prism
  - Matemáticas con KaTeX
  - Custom theme swizzling en src/theme/
  - Sidebar automático desde sidebars.js
  - Datos en tiempo real via autogenerated
  - Chatbot RAG sin backend externo (api/chat.js)
  - CSP restrictiva (para seguridad)
  - Lazy loading de scripts (KaTeX via CDN)

PUNTOS CRÍTICOS PARA OPUS:
  1. routeBasePath: '/' → docs se sirven en raíz, no en /docs/
  2. customCss: custom.css es la única hoja global (sin Tailwind)
  3. theme/MDXComponents.js puede registrar componentes globales
  4. Sidebar autogenerated para datos-tiempo-real → puede causar orden inesperado
  5. Vercel CSP es restrictiva pero permite unsafe-inline/eval en script-src
