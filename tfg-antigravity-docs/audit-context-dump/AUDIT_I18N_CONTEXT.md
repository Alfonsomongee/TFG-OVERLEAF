# Contexto de Internacionalización (i18n) — TFG Docusaurus/React

Este documento analiza la estructura del sistema multiidioma (i18n) y evalúa el nivel de paridad entre la documentación original en español y las traducciones disponibles.

## 1. Configuración de Idiomas
Docusaurus tiene configurado el soporte para cuatro idiomas (`docusaurus.config.js`):
- **Español (`es`)**: Idioma por defecto.
- **Inglés (`en`)**
- **Alemán (`de`)**
- **Chino Simplificado (`zh-Hans`)**

La estructura de carpetas de traducción es la siguiente:
- `i18n/{locale}/docusaurus-plugin-content-docs/current/`: Documentos MDX traducidos.
- `i18n/{locale}/docusaurus-theme-classic/`: Elementos comunes de la interfaz (navbar, footer, sidebar).
